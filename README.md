# IdeaLab

个人创意实验室，记录灵感、调研与原型实验。每个创意项目在 `ideas/` 下拥有独立目录。

## 项目索引

- [Marble](ideas/Marble/README.md) · 灵感记录

## 新建创意

复制 [统一创意模板](templates/IDEA_TEMPLATE.md) 到 `ideas/<项目名>/README.md`，先写灵感卡，再把项目链接加入上面的索引。进入调研、验证或开发后，按需补充推进记录。

### 用 ChatGPT 记录

> 帮我把这个新点子记录到 IdeaLab（VJ-VickWeijie/IdeaLab）。想法是……

这句话表示可以直接整理并提交到 GitHub。项目名可选，只有一句描述也可以先记录。创建项目时，在 `ideas/<项目名>/README.md` 写入灵感卡，并把项目加入索引。

要补充已有项目，可以说「把下面这条补到 IdeaLab 的 Marble 项目里」。想先聊聊，可以说「先讨论这个点子」。
