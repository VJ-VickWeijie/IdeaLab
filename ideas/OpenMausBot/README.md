# OpenMausBot

## 灵感卡

- **一句话想法**｜学会使用 OpenMausBot，再评估它的交互设计、工作流和实现思路能否用在我们自己的项目里。
- **灵感起点**｜在 GitHub 发现了这个开源项目。上游 README 把它介绍为一款聊天式桌面应用，可以把多个 AI 助手配置成不同的聊天联系人，并在对话中处理操作审批。
- **最想保留的点**｜体验不同助手怎样分工，观察用户如何看到任务进展、确认关键操作。评估时把「可借鉴的交互和流程」与「可复用的实现」分开记录。
- **当前状态**｜灵感，待试用。
- **下次打开时**｜先查看 Windows 安装和所需的代理配置。配一个 Codex 助手，用测试目录跑一轮「阅读项目说明 → 给出建议 → 确认后写入一份笔记」，记录各步体验，再挑一个现有项目对照，看哪些做法能解决实际问题。
