# Marble V0.2｜温馨森林五屏视觉基准稿 V1

日期：2026-11-17
状态：**用户认可新版视觉方向，可作为后续 UI 设计基准；尚非最终开发验收。**

## 五屏内容
1. 0–2 岁探索首页：大入口、亲子友好、继续探索。
2. 连续认知页：大型真实香蕉图片，点击图片才朗读；上滑下一个、下滑上一个，切换时停止前一音频；**不使用独立的大型「点击播放」按钮**。图片上的播放标识只提示可点击。
3. 知识详情页：照片优先，降低低龄文字密度；图片放大与音频交互需区别于连续认知模式。
4. 家长陪读抽屉：亲子讲解、适龄观察、安全提示；提示根据具体知识而非套用统一警告。
5. 知识地图：当前知识与关联节点；0–2 岁按已确认的当前节点 + 2–3 个大图片关联节点呈现，进一步扩展暂缓。

## 视觉基线
- 同一套温馨森林皮肤贯穿五屏；森林绿、奶油白、暖黄色、圆角组件与柔和装饰。
- 内容页比首页更简洁，减少背景干扰；保持大型可触控区域。
- 多主题皮肤功能仍保留，用户手动选定后全局一致，不随知识内容自动换肤。
