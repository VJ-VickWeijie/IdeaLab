### Android 離線模擬器

- API 26 AOSP x86_64（軟件模擬，540 × 960）。乾淨安裝前確認飛行模式開啟、Wi-Fi 同流動數據關閉。相同 SHA-256 開發 APK 成功安裝、啟動並通過兩項 Compose 操作測試。
- `groupsSearchAndHistoryClear` 驗證手動 1–2 歲、6 張卡片、重看與換組、`banana` 搜尋、返回原搜尋、探索記錄、清除後重建及保留年齡。
- `cardGesturesReadingMapAndRestore` 驗證點圖、短拖、取消手勢、上下滑、陪讀、香蕉地圖入蘋果、Activity 重建及返回原地圖與圖卡。實際記錄到音頻焦點申請及放棄。模擬器啟動時停用聲音輸出，聽感、耳機同聲道另待真機。
- 五個實際畫面依序為首頁、連續卡片、知識詳情、家長陪讀及知識地圖。[API 26 五屏截圖](evidence/m4-api26-five-screens.webp)
- API 37 AOSP x86_64（軟件模擬）已完成 APK 斷網安裝。重試確認飛行模式開啟、Wi-Fi 與流動數據關閉，Android 顯示 `Active default network: none`。路由表遺留項只指向本機 `dummy0`。
- API 37 的首次 Activity 啟動在 29.7 秒逾時。Compose runner 亦未完成，Android 記錄 App 程序啟動 ANR，系統電話程序同期反覆啟動 ANR，系統 CPU 壓力偏高。安裝已驗證，完整流程及啟動效能保留待硬件加速模擬器或真機複驗。
