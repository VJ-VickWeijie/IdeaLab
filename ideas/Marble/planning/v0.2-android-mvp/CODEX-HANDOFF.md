# Codex 開發總指令｜Marble V0.2

交接對象為一個 Codex 主任務。以下指令須在所有者明確採納規劃並授權 M4 後使用。

> 接手 GitHub `VJ-VickWeijie/IdeaLab` 的 Marble V0.2 Android MVP。採用「Work 一次規劃、Codex 一次接手、各階段自主執行」。我是本次交接的協調者。你擔任實施協調與開發負責人，從批准版本自行恢復上下文、拆分工作、分配角色、完成構建和回歸，將可驗證成果交回 IdeaLab。
>
> **先核准入。** 讀取 IdeaLab 根 README 與 AGENTS → Marble README、最新批准決定、設計與原型 → `docs/AI_WORKFLOW_INTEGRATION.md` → 獨立 AI-Workflow 固定提交 `939ec44036d89cd91622ab96b938be9f02479026` 的 README、生命週期、組隊、模型、門禁及交接規範。再讀獲批准 GitHub ref 的 `ideas/Marble/planning/v0.2-android-mvp/` 全套規劃，鎖定最新 `main` 基線。引用明確的所有者 M4 授權、批准的規劃 commit 或 PR 及批准範圍。只提供本指令或只批准方案時將狀態留在 M3。若規劃仍在草稿分支，讀取指向實際批准版本的 commit；需要以其內容建立實作基線時，可納入批准的規劃文件，保留可追溯的來源。
>
> **目標和約束。** 交付供審閱的 0–2 歲家庭內測 Android APK，溫馨森林單主題、粵語離線講解及對應文字、實物圖認知與家長陪讀。完成 T01 的 R01–R10。首頁可去有限連續認知、親子與繼續探索；整圖主動播放、上／下滑操作與切卡停音；普通知識詳情上下滾動且可獨立放大照片；簡化地圖從關聯節點進普通詳情、返回恢復；年齡／深度、文字別名搜尋、歷史及清除均可離線用。首次無網可用，內容文字、照片與必要粵語錄音隨 APK，保持上游 ID／內容的來源邊界。英文和多主題、動物聲音比較與雨水動畫、NAS、帳號、同步、外部 AI／遙測、批量內容和部署均在批准的實施邊界之外。
>
> **自主實施。** 執行 T05 的 W00–W06。先固定構建工具鏈、API 與簽章安排，按 T02 驗證離線資料契約、本地資料和 Android 音頻焦點。用已准入小內容驗證三條路線：首頁 → 滑滑／整圖播放；香蕉詳情 → 陪讀；香蕉地圖 → 蘋果普通詳情 → 返回原地圖及詳情。安排可並行且互斥的資料／內容工作，迭代至 T01 全部核心流程，按 T03 做首批內容及媒體准入。先用小組測通再擴至可交付包，螢幕錄影、圖片及音頻仍須遵守素材准入。團隊按實際工具、可用模型及成本組織，技術難點和獨立審閱優先用合適的獨立上下文；如不可用，記錄實際做法和覆核缺口。日常分工、刻意回歸與返工自行處理。中斷或續接時以 GitHub 工作分支的任務／測試狀態恢復。
>
> **驗收。** 按 T04 完成 UX01–UX10、SYS01–SYS07、CT01。將原理／單測、模擬器、兼容真機及家庭目標真機的結果分開。重點收集乾淨安裝後飛航模式首啟、整圖點按／短拖／切卡／停音、地圖往返、陪讀、系統返回與旋轉、鎖屏及焦點／耳機中斷、素材損壞降級、同簽章更新和本機資料刪除。每條寫明版本、設備、步驟、預期、實際和證據。缺少設備或授權時標相應阻塞，完成其他可做工作。S1/S2 先修復再複測，已批准條件受影響時送回規劃與所有者決策。
>
> **交付與門禁。** 只在批准分支提交，提供待審 PR、可重現的構建命令、簽章 APK、SHA-256、版本與簽章指紋、內容／許可清單、測試證據、已知問題和階段報告。發行簽章材料、家庭裝置辨識資訊和真實出生日期留在受控環境。M4 實作與 M5 獨立審閱分別保存證據，依所有者批准的門禁等待或交接。新增費用、重大技術／產品變更、敏感資料流、公開分發、家庭試用發布、部署及重要 PR 合併須先獲明確批准。交完整結果給所有者決定，停在批准的邊界。
