# T01｜0–2 歲 Android MVP 產品範圍

狀態為 M2/M3 待所有者審批。首版共識源於 MVP 任務書 V1.2 與本輪 M2/M3 規劃授權。既有細節依 [產品決策](../../design/V0.2-product-decisions-2026-11-17.md) 及 [UI/UX 規範 §11](../../design/V0.2-UIUX-spec-2026-11-17.md)。本頁所列 P0 是建議納入首版的完整交付基線，驗證入口見 [T04](T04-acceptance.md)。

## 首版交付

| 需求 | P0 行為 | 驗收關聯 |
| --- | --- | --- |
| R01 安裝與離線 | 單一 Android APK，從乾淨安裝起即可離線走完核心流程。附帶知識文字、圖片和必要粵語音頻。應用每次正常冷啟先到首頁，提供「繼續探索」。 | SYS01、SYS05、SYS07 |
| R02 年齡與解釋 | 家長可輸入出生日期以自動選擇 0–1 或 1–2 歲體驗，或使用手動體驗年齡。解釋深度獨立保存與調整。 | SYS02、SYS06 |
| R03 首頁與主題 | 溫馨森林貫穿五屏。首頁以「滑滑認識世界」、親子共學和繼續探索為重點，附少量推薦、主題分類入口及供家長使用的文字搜尋。家長共學入口可挑選適合一起看的項目並開啟該項陪讀。 | UX01、UX02、UX08、UX09 |
| R04 有限連續認知 | 首包 0–1 歲每組預設 5 張、1–2 歲預設 6 張。內容配置可在建議 5–8 張內調整，小月齡可用較短組。各組其餘已准入節點仍可從分類、搜尋或關聯開啟。上滑下一張，下滑上一張；越過觸控閾值的手勢取消點擊。第一張向後不越界，末張有重看、換組及回首頁，換組由使用者主動觸發。 | UX02、UX03、UX04 |
| R05 普通知識詳情 | 先給簡短答案，照片優先，有近一步的解釋或相關內容時由家長主動開啟。上下滑動只滾動；放大入口獨立於播放。整圖主動播放或自頭重播本項粵語講解，角落小型半透明喇叭提供視覺提示；沒有音頻時隱藏喇叭及播放語義，保留可讀內容。 | UX01、UX03–UX05、UX10 |
| R06 親子陪讀 | 支援由首頁及知識流程進入，提供可自然朗讀的粵語書面稿、適用時的可選觀察與簡短風險提醒。陪讀配音可選。打開或關閉抽屜、進入照片放大時停止當前聲音，返回由使用者重新點按。 | UX04、UX06、UX10、CT01 |
| R07 低齡知識地圖 | 當前節點 + 2–3 個大型實物圖片關聯節點。點關聯節點進普通詳情；頂部及底部返回入口依來源標示。返回保留原中心、節點順序與視角，亦保留來源詳情滾動、展開和深度。 | UX05、UX07、SYS03 |
| R08 搜尋與歷史 | 按入包名稱和審核別名離線搜尋，例「香蕉」「banana」。記錄有意義的知識跳轉；同一項重播與滾動不累加歷史。連續認知切卡只更新繼續探索進度。提供家長查看、清除歷史和全部本地資料功能。 | UX09、SYS05、SYS06 |
| R09 首個內容包 | 以約 20–30 個候選規劃素材工作量，入包以經核查的可用分組覆蓋為準。每個核心節點有可辨識實拍、本地適齡文字及必要粵語短講解，陪讀稿必備，資產失效時降級。 | UX10、CT01、SYS01 |
| R10 播放與系統狀態 | 連續認知與低齡詳情共用主動播放規則，滑動或返回時不自動朗讀，切卡、離開、失去焦點或中斷時停音，音頻不在背景續播或自動恢復。 | UX04、SYS03、SYS04 |

### 需採納的實作細節

- 自動段位以本地民用日期和生日為界，出生至一歲生日前為 0–1，滿一歲至兩歲生日前為 1–2。出生日期可略過，預設 0–1；拒絕無效或未來輸入。閏日出生者在平年以 2 月 28 日作為產品段位切換日。滿兩歲以上顯示本版範圍提示，提供 1–2 的可用內容及手動調整。手動檔及解釋深度分開，返回自動後重新計算。出生日期僅作本機計算，不要求姓名或帳號。
- 持久化的「繼續探索」以有效知識 ID 定位，連續認知可另存組別與卡片位置。清除歷史同時移除繼續入口與相關快照；清除動作本身不寫回當前節點。清除全部本地資料亦清除出生日期和手動設定，回到乾淨首頁。旋轉或系統重建可恢復有效導航狀態；由啟動器冷開、沒有系統待恢復任務時，從首頁開始。
- 低齡主要控件建議至少 56 dp，首頁主入口、主圖及關聯圖節點更大；真機以可點範圍測量。滑動與點按應有對等無障礙操作，短拖不切卡也不發聲。無需借用森林概念圖中的收藏、主圖獨立播放圖示或額外節點作為首版需求。
- 家長抽屜打開先停音、關閉不續播，是本方案對尚待驗證規則的推薦。棕綠文字對比、照片裁切及系統大字可讀性由真機檢查。
- **首版新增強制操作數量為 0。** 不強制設定生日、回答問題、完成一組或執行感官活動。解釋更深時，安全邊界維持相同。

## 原型轉首版的差異

| 基線 | Android 首版 | 依據 |
| --- | --- | --- |
| 原型 PR #8 的五個主要畫面 | 保留首頁、連續認知、知識詳情、陪讀及地圖的功能閉環。按截圖核對森林色板、照片層級和大觸控；低齡地圖以 2–3 大圖節點為準。 | 視覺稿是風格基準；產品決策 §收尾及 UI/UX §11 定義交互優先級。 |
| 瀏覽器即時語音、遠端圖片 | APK 內置可追溯的實拍和核准粵語檔，離線點按正常，故障時仍可閱讀並繼續探索。 | R01、R05、R09。 |
| 網頁暫存及簡單導航 | 設定、歷史、繼續探索在本地保存；導航和歷史分開，實測 Android 返回、旋轉、程序重建與更新。 | R02、R07、R08。 |
| 主題切換、多語切換缺失 | 本版全局森林＋粵語講解及對應文字。UX08 驗證單主題跨五屏，UX09 驗證搜尋、歷史與粵語配對。 | 使用者批准單主題、保留長期多主題，並延後英文。 |
| 動物專屬聲音比較、雨水專屬動畫 | 首版內容聚焦實物圖片與陪讀，專屬玩法保留後續；原型媒體及按鈕行為保留作歷史參考。 | 使用者批准分期。 |

| 優先級 | 項目 | 承接條件 |
