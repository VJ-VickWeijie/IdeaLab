## 1. 测试对象与设备

每个发布候选固定应用版本、`versionCode`、源码提交、内容包版本、APK SHA-256、签名证书指纹。自动化可使用测试构建与故障素材，家庭试用候选使用同一份可独立安装的已签名 APK 完成最终复验。用测试资料完成生日、历史、备份和清除用例。只在专用测试安装上卸载、清数据、恢复备份或模拟换机。

| 设备 | 目标与最低覆盖 | 当前状态 |
| --- | --- | --- |
| 家庭目标 Android 真机 | 系统安装器、真正断网、五屏和滑动手感、粤语音频、系统返回、重启及候选升级。记录机型、Android 版本、ROM、屏幕/字体设置与导航方式 | 具体型号、系统版本、可用时间待核对。缺真机证据时家庭试用结论保持有阻塞 |
| 可取得的备用 Android 真机 | 尽量选择另一厂商或较低配置，检查音频焦点争用、拔耳机/蓝牙断连与厂商备份/换机行为。记录实测覆盖，标出设备特有差异 | 待落实设备，不将模拟器证据记为真机证据 |
| API 26、31 模拟器 | 候选最低 API 26 上安装、断网、滚动及音频冒烟；API 31 上回归音频焦点变化、备份排除、系统布局与旋转 | 计划覆盖 |
| API 35/36、37 模拟器 | API 35 或 36 覆盖现代返回、焦点、应用窗口切换；候选目标 API 37 覆盖同类回归及 ≥600 dp、横屏、分屏和放大字体下的关键控件可见性 | 计划覆盖，使用 T02 最终批准的 SDK 配置 |

实测优先使用系统安装器与默认日常设置，再用 ADB、Compose UI 测试、静态资源检查和故障构建补足可重复证据。记录模拟器实际镜像级别。目标真机低于批准的最低 API 时，报告兼容风险并回到 T02 评估。 [ADB](https://developer.android.com/tools/adb) · [APK 签名验证](https://developer.android.com/tools/apksigner) · [Android 17 SDK](https://developer.android.com/about/versions/17/setup-sdk)

## 2. UX 验收断言

| 编号／首版范围 | 测试步骤 | 通过条件及证据 |
| --- | --- | --- |
| UX01 五屏视觉与首页 | 从首页进入推荐及主题分类，通过主入口依次打开连续认知、知识详情、家长陪读、知识地图。对照五屏基准，在正常与放大字体各遍历一次 | 首页入口优先级、五屏照片层级、组件与导航符合森林基准。推荐及分类进入对应内容，名称和主操作始终可见或可滚动到达。留五屏截图与差异记录 |
| UX02 触控与可达性 | 在目标真机核对首页主入口、整图、卡片结束动作、地图关联节点、返回等触区。点边缘、点两项之间空隙。开 TalkBack 单独试阅读、播放、下一张、上一张及返回 | 低龄关键目标建议至少 56 dp，主图等主要操作面更大。一次点按只触发预期操作，贴边系统返回与页面操作无冲突。整图提供明确播放/重播语义，角落图标无竞争焦点。滑动切卡可通过等效无障碍动作完成。留尺寸和实际操作证据 |
| UX03 卡片组、手势与普通详情 | 在两年龄档进入连续认知，浏览一个完整组。做轻点、短拖、斜拖、完整上下滑、快速连滑；在首尾继续划；分别触发重看、换组、回首页。点卡片的详情，再从地图进另一知识并上下滚 | 上滑下一张、下滑上一张，每次手势最多切一张，短拖和不成立的纵向手势不切卡也不播放。组长用 T01 批准的年龄设置；首尾有边界，末项三个动作有效。详情只有当前知识纵向滚动。录卡片标识或顺序与实际音频 |
| UX04 整图播放及放大分离 | 在连续认知和低龄图片详情分别点图中间、远离喇叭的边缘与角落，再点一次；在播放期间切卡、快速点新图、放大图片、返回或离页。另做点 A 后立即划到 B、连点 B 后马上进入地图的竞态 | 主图可在任意有效区域主动播放/重播对应本地粤语；同一时刻只有一段，旧片及时停止且准备中的旧片不迟到。滑动和返回均静音，放大入口只放大，图上只有小型半透明扬声器提示。留系统音频/外录与录屏，必要时附播放事件时间，不录家庭对话 |
| UX05 返回与恢复 | 在香蕉详情选择较深解释、展开可选区域并滚到明显段落；打开香蕉地图，点苹果进入详情，再探索下一节点。按层使用页面返回与 Android 系统返回，回地图后按底部按钮；若设计中从首页直接进入地图，则另测对应返回 | 每次回到准确来源。香蕉地图恢复中心、关联节点、相对位置和已有展开状态，香蕉详情恢复段落位置、展开及解释深度，连续认知来源恢复原组和卡片。不同屏幕尺寸下以内容锚点和相对布局判定，不比对像素绝对值。全过程无自动重播。留完整导航录屏 |
| UX06 家长陪读 | 从首页到亲子入口，从正在播放的连续认知和详情打开当前知识的抽屉；在小屏/大字下滚动末行，分别验证有声和纯文字陪读。候选无独立陪读音频时用专用测试内容包验证有声分支。分别用关闭键与系统返回关闭抽屉 | 家长可以直接自然朗读，说明、可选观察及适用提醒可读。打开抽屉即停上一段，纯文字陪读仍完整可读且不显示失效播放入口；有声分支仅主动触发，关闭即停且不恢复之前音频。关键控件不被遮挡，退出回到原内容；无需答题或完成动作。留抽屉截图与音频证据 |
| UX07 低龄知识地图 | 按两个年龄档巡查包内可访问地图（至少真机验证香蕉路线）。点各图节点、回地图、再走地图底部返回；对内容包关系做全量引用检查 | 地图展示当前中心与 2–3 个可操作大图片节点，连线清楚。节点均进入普通详情，明示返回入口按来源返回，节点与关系可解析。媒体异常适用 UX10 的可读降级。留节点计数、关系检查结果和操作录屏 |
| UX08 温馨森林全局一致 | 改变体验年龄、浏览不同类别及知识深度、跨五屏后重开应用，对比配色及图文 | 五屏保持同一主题，文字与背景可辨，事物照片、知识语义与导航一致。留主题截图及与基准的差异记录 |
| UX09 文字搜索、历史及粤语 | 搜索名称、简繁或英文已登记别名、空白及无结果词，试大小写和空白归一化。用搜索和地图明确打开知识，再播放、滚动和返回。分开从详情和连续卡片中段重启，测试首页继续，再到家长入口清历史并重启 | 正式条目及配置好的别名可命中，无结果有提示。详情或地图跳转按规则记录，连续重复及纯交互不累加历史；连续卡片另存有效组/项锚点。常规重启先到首页，继续恢复有效知识或继续卡片。清历史同时移除继续入口，在途写入不会回填，下次主动跳转可正常记录。设置未受影响。首版以粤语音频与对应文字验收 |
| UX10 媒体异常与现实建议 | 在校验阶段制作只用于测试的缺图、坏图、缺音频或坏音频构建／注入场景，并对照有效构建。打开详情、放大、陪读及含故障节点的地图，点击缺音频主图再切到正常节点；重新测试恢复有效媒体；抽查亲子建议 | 缺图仍显示名称与文字，放大或地图均可退出。清单可识别的无音频隐藏喇叭和播放语义，损坏文件触发时给短提示，均保持可读内容，无无限重试、串音或联网回退。恢复有效包后媒体正常，无陈旧占位。活动为可选、适龄，面向具体知识，内容门禁见 CT01。留故障输入、恢复步骤、画面与音频 |

UX07 的低龄扩大地图机制和其他年龄地图能力不在首版；UX08 多主题及切换、UX09 多语言切换和英文字幕/独立配音、原型里的动物声音比较及雨水专项动画均为已批准延期，保留后续检查编号及来源。UX10 的首版降级只覆盖实际随包媒体。 [温馨森林五屏基准](../../design/V0.2-forest-five-screen-visual-review-V1.md) · [五屏稿](../../design/assets/marble-v0.2-forest-five-screen-V1.png)

## 3. 系统、离线和内容验收

| 编号／首版范围 | 测试步骤 | 通过条件及证据 |
| --- | --- | --- |
| SYS01 真机离线安装和运行 | 把签名候选 APK 通过 USB 复制至测试手机，开启飞行模式，确认 Wi-Fi 与蜂窝数据关闭且设备未接有线网络。在测试设备上从无安装状态用系统安装器完成安装，且首次启动前无旧数据。一直断网走首页、年龄、两种连续组、详情/放大、陪读、地图、搜索、历史；强停后重进验证继续及媒体，再清历史、重启验证继续入口消失 | 安装及首次启动成功，核心图片、文字和必要粤语音频来自内置包，无网络、登录或首次下载依赖。断网关闭应用后重新启动仍可见本地状态或已清除状态。留安装、网络设置、主路径录屏与版本指纹 |
| SYS02 适龄设置 | 固定测试日期，用合成生日验证空值、当天出生、1 周岁前一日/当天、2 周岁前一日/当天、未来日期、无效日期；另测跨月/跨年重进、闰日边界，记录固定日历计算口径。设置手动档及解释深度后重启，再还原自动。检查首页继续入口与年龄提示 | 无日期为幼龄默认；出生至 1 周岁前为 0–1，满 1 岁至 2 周岁前为 1–2；超过覆盖范围按 T01 使用可用较大档并提示。平年 2 月 28 日切换闰日出生者的档位；无效或未来日期不覆盖已有值。手动档与解释深度彼此独立且能持久保存，回自动按当前日期重算。全程仅用合成数据；录屏加边界单测输出 |
| SYS03 系统返回、旋转和进程重建 | 在详情带地图来源、卡片中段及陪读层进行旋转、横屏转回、分屏和 Android 返回手势或三键返回。播放中切后台，测试系统回收后由最近任务重建；与显式强停后的冷启动分别记录 | 返回先关闭当前抽屉/放大层，再按导航栈恢复；旋转保持可读内容、当前节点、卡片位置或滚动锚点，音频停止且不自动续播。系统恢复最近任务时按 T02 恢复代数及内容均有效的路由且不新增历史，失效则回首页；显式重启回首页并出现有效继续入口。记录前后状态和是否由系统恢复任务。 [Compose 状态保存](https://developer.android.com/develop/ui/compose/state-saving) |
| SYS04 音频中断 | 播放一段足够操作的离线粤语测试音频。分别切到后台/锁屏，在另一测试 App 请求焦点，模拟系统临时或永久焦点丢失，拔出耳机或断开蓝牙；复现获焦失败并返回 App，再点主图 | 焦点丢失、输出设备断开或后台状态立即停旧片，保持单播放器，无突然外放、焦点恢复后的自动续播或错误片段。回前台并再次主动点图、成功获焦才播放。现代系统失败时保留可读状态，允许手动重试。录屏与系统音频互证。 [Android 音频焦点](https://developer.android.com/media/optimize/audio-focus) |
| SYS05 同签名升级与内容变更 | 安装先前可用或专用升级测试版本 A，写入合成设置/历史/继续。断网升级到同包名、同签名、更高 `versionCode` 的版本 B，检查保留 ID、更名 alias、无替代移除。另测不可解析内容包及后续修复 APK，复验历史和设置。用错误签名替换包演练拒装 | 正确签名保留仍有效记录，alias 可解析，移除项无死链，清除标记不会被恢复。内容版本整包一致，遇包损坏能读到错误提示，数据仍保留且在更高版本的修复 APK 可再次读取。错误签名包无法替换，原数据仍可读。留版本、签名指纹、升级前后记录和迁移测试结果 |
| SYS06 资料删除、备份与联网边界 | 检查最终 APK Manifest、SDK 依赖、备份配置与私有存储位置。用测试数据检查离线和联网工况、崩溃或异常日志。分别测试清历史及全清。各自在清除前捕获非首页导航快照，清除后从最近任务重建并用测试夹具提交旧代数快照及排队写入；另检查强停重启和应用清除。用专用测试环境分别做 Android 云备份恢复及设备换机传输，记录可用的跨平台迁移路径、实测结果和缺少的设备条件 | 无 `INTERNET`、位置、相机或录音权限、账号或行为分析，设置/历史仅留设备，原始生日与历史均未进入日志。清历史保留设置，全清回干净首页并重置设置，两者的历史及继续均为空。旧代数导航快照或写入均被忽略，系统返回与进程重建不能恢复。云备份和已测迁移路径不带回资料。静态排除和实测分别记账，无环境可操作的迁移路径保持未验证。 [Android Auto Backup](https://developer.android.com/identity/data/autobackup) |
| SYS07 包体与可用首屏 | 对正式签名的通用 APK 记录二进制字节数和分项资源大小；在目标真机断网、固定设备条件下，从强停状态独立执行 5 次启动，分别记录启动到首页主入口可操作的耗时 | 以 T02 最终批准预算验收。当前建议 APK ≤40 MiB，媒体与设计资源目标 ≤20 MiB，5 次冷启动的最慢一次 ≤3 秒。附 5 次原值、测试工具与设备条件。建议目标测不到时记录瓶颈，首屏卡死按 S1 或 S2 |
| CT01 内容包完整性及准入 | 对候选 APK 的实际入包清单检查知识/分龄呈现/关系/分组、每个媒体引用、版权署名与审校签字。人工逐条核对图文一致、粤语读音、年龄差异、可选活动，对有意缺损与发布配置各跑一遍 | 只有事实和版权均已核查、必要图片和音频有效、适龄呈现完整的条目进入正式包。占位素材、原型远程链接、未经审校译文、悬空关联或重复 ID 被检查拦截。记录内容包版本、审核人和素材许可，故障注入内容仅用于测试。候选数量为规划值，首版仍须支持重看和换组的完整体验。 [上游来源说明](../../upstream/PROVENANCE.md) |

## 4. 回归顺序与批准点

1. **M3 规划审阅**。确认用例能追溯到已批准的规则，记录未验证条件、目标设备与 QA 资源。完成本文仅代表测试计划可审阅。
2. **M4 第一轮纵切**。在已批准开工后，用少量样板贯通真实设备干净安装、断网、卡片/详情、停音和返回。为首次可安装版本保留同签名的前后版本作为升级证据。样板结果用于降风险，候选媒体仍须通过 CT01。
3. **M4 每轮回归**。提交后至少重跑内容校验、年龄边界、关系完整性、搜索/清除、迁移、手势判定、单播放器竞态自动测试。导航或媒体修改后补跑 UX03–UX07、UX10、SYS03–SYS04；内容包、权限或存储变更后补跑 SYS01、SYS05–SYS06、CT01。关键证据附到对应构建。
4. **M4 候选自检与 M5 独立复验**。独立审查者核对 T01 和原始证据，并在真机亲自复跑 SYS01、UX02–UX07、UX09、SYS03–SYS04 和适用隐私路径，按同一 APK 指纹验证。若不能直接操作真机，记录实际操作人、证据覆盖与阻塞。完整性、许可和签名逐项核对。每个修复在新构建复现原用例后补邻近回归。家庭试用由所有者按 M5 结果审批。

| 等级 | 例子 | 处理 |
| --- | --- | --- |
