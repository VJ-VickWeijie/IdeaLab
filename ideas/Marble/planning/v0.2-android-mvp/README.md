# Marble V0.2｜0–2 歲 Android MVP 規劃

**目前階段** M2 專業方案與 M3 實施規劃

**審批狀態** 等待所有者採納方案和明確授權 M4

**上輪狀態** 所有者已實際試用並認可原型方向。真機操作與離線等驗收留待 Android 候選版本。

方案建議採用 Kotlin、Jetpack Compose 與 APK 隨附內容包，交付一個可在無網裝置完成核心親子探索的 Android 初版。已批准的產品取捨為 0–2 歲、溫馨森林、粵語講解與對應文字，首版聚焦圖片認知與家長陪讀。首批以小規模本地內容、可辨識的實拍、必要粵語音頻和審校記錄驗證閉環。
