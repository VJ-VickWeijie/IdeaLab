# T05｜M4 實施工作包與風險

狀態為待所有者批准。T01–T04 對應產品、架構、內容與驗收。以下工作包是 Codex 獲得明確 M4 授權後的執行順序。家長仍可在最終 APK 驗收時決定家庭試用。

## 工作包

| 包 | 負責角色與寫入邊界 | 前置 | 可交付與完成條件 | 驗證及回退 |
| --- | --- | --- | --- | --- |
| W00 啟動與工具鏈 | Codex 主代理／Android 工程，工作分支及構建設定 | M3 獲採納、另有 M4 授權 | 固定 SDK、JDK、Gradle、AGP 和依賴；記錄目標機型／版本及 APK 簽章持有人，確認從乾淨 checkout 可構建及在題定 API 驗證。 | 記錄工具鏈和構建命令。SDK 版本異常先排查兼容；變更主要方案或支持門檻回 M2/M3。無真機可先並行做工具鏈與單測，具體機型在真機驗證前補齊。 |
| W01 離線內容讀取與本地儲存 | Android 資料工程，內容載入、設定／歷史及資料契約 | W00、T02 | 驗證內容版本、引用 ID 及必要資源；穩定本機資料、搜索索引、歷史與清除、可重入更新；新增單測。 | SYS02、SYS05、SYS06、UX09。用小測試包測錯誤、缺檔及遷移；上游維持原樣，遷移失敗資料保留並回到責任人。 |
| W02 真機垂直閉環 | Android 互動工程，導航與音頻共用層、手勢與首組流程 | W00，先用 W01 契約及經許可測試素材 | 跑通首頁 → 點圖／上滑 → 香蕉詳情 → 陪讀 → 香蕉地圖 → 蘋果 → 返回。驗證旋轉、快速切換、前後台與系統中斷。 | UX03–07、SYS03–04。先收實機/模擬器證據再擴屏；短拖誤發聲、主流程失音或導航還原失敗屬 S2，修好再擴。 |
| W03 五屏與家長功能 | 產品 UX＋Android，頁面組件及可達性 | W01、W02 | 森林五屏、適齡與解釋深度、首頁群組／搜索、親子入口、繼續入口、歷史及清除齊備。附五屏圖及識別可點範圍。 | UX01–09、SYS02、SYS03、SYS06。優先保住核心互動；不影響首版的細節用 S3/S4 紀錄。 |
| W04 首批媒體與內容准入 | 內容編輯／粵語與事實安全複核，內容包、媒體清單及授權記錄 | T03 已採納；W01 格式確認後整合，可與 W01–W03 的可獨立製作工作並行 | 每項記錄事實審校、適齡呈現、錄音與文字匹配、圖片／聲音許可及署名。先以已准入的小組反覆核對，再整合可交付組。 | CT01、UX10；有疑點的媒體隔離並換用審核通過且語義等效的素材，檢查分組、搜尋和地圖仍閉合。影響 R09 的變更回所有者。 |
| W05 發行候選及回歸 | Android 發行＋測試，簽章 APK、測試記錄與候選版本 | W01–W04 | 可核對 commit、APK SHA-256、versionCode、簽章指紋、資料包版本與測試路線。完成乾淨安裝、飛航模式、跨版更新、退回路徑及家庭機矩陣。 | T04 全套。簽章不一致不得用卸載掩蓋遷移失敗。阻斷真機、授權或資源問題列出受影響測試，其餘工作繼續。 |
| W06 獨立複核及交付 | 與實作者分開的審查角色；最後由所有者驗收 | W05，按批准的 M4/M5 門禁 | 獨立角色檢查準入、原始運行證據、缺陷及重測。交 APK、證據、限制及待審 PR。 | M4 自檢與 M5 複核各自存檔；S1/S2 修復及重測；未解項與證據交所有者審閱，維持家庭試用阻斷。提交驗收後等待家庭試用決定。 |

工作分流按 W00 → W01/W02 小閉環 → W03 → W05 → W06 執行。W04 從獲准即開展，與互動工程使用互斥寫入路徑，W05 匯合。重疊修改先由同一責任人整合；普通缺陷迴圈「修正 → 重測 → 回報」由主代理維持。若分支中斷，從相同 refs、工作包狀態及測試結果恢復。

## 投入與資源假設

| 方向 | 粗估有效工日 | 驗證資源 |
| --- | ---: | --- |
| W00–W02 構建、資料、互動閉環 | 4–6 | 可用 Android SDK/JDK、USB 安裝權限、模擬器、可重製構建。 |
| W03 五屏及家長功能 | 3–5 | 已確認五屏視覺與 T01；真機錄影及 TalkBack。 |
| W04 小規模內容及媒體 | 3–6 | 主要取決於機型以外的人審與粵語錄音／授權可得性，可並行。 |
| W05–W06 整合、驗收與返工 | 3–5 | 家庭目標機及可用的兼容真機；APK 簽章、審查和重測。 |

合計約 **13–22 有效工日**，是工作量估算。實際日曆時程視並行程度、素材可得性、簽章與真機窗口而定。沿用現有 Work/Codex 資源和免費 Android 工具鏈，額外支出按 **¥0** 規劃。需付費照片、錄音、測試雲或其他服務時，先列費用和免費路徑，再交所有者選擇。

## 風險與早期驗證

| 風險 | 何時檢查／責任角色 | 處置 |
| --- | --- | --- |
| 提前把原型瀏覽器播放、尺寸或動態行為視為已通過 | W02，Android／QA | 在真機錄一遍全流程，分開靜態、模擬器、真機證據。未取得真機資料時將相應條目保留未驗證。 |
| 舊設備性能、Android 新版邊緣顯示、返回及焦點差異 | W00/W02，Android／QA | 先測最窄機及家庭機。若 API/工具鏈目標需大改，提交數據和回退條件。 |
| 粵語或圖片准入拖延 | W04，內容／粵語審閱 | 先完成可核查小組。必要語音與可辨圖逐項核驗，審閱人缺席的內容暫留候選。 |
| 歷史和生日經備份、裝置傳輸、錯誤日誌外流 | W01/W05，Android／QA | 使用排除備份的專用儲存，核對合併權限及備份規則，依 T04 真機取證。 |
| APK 變大或更新簽章不連續 | W00/W05，Android 發行 | 根據 T02 量測資源與整包，保存證書指紋與版本對照。使用同簽章升級並重驗；保留上一版構建與前向修復方式。 |
| 內容包換版使地圖、歷史或繼續入口失去引用 | W01/W05，Android 資料 | 保持穩定 ID，對已撤回或無法解析的 ID 進行一致的降級，更新後回歸搜索、返回、歷史及清除。 |
| 上游資料、第三方照片、錄音聲線或示意素材權利不明 | W04/W06，內容審閱 | 按 T03 建檔，以可核驗且獲准素材入包。若採用上游改編或錄音，需要按該項來源及存放和分發方式完成核查。 |

## GitHub 與審批

- 規劃交付使用獨立文件分支與草稿 PR，歷史設計、原型及上游檔案保留作溯源。所有者核准時應記錄實際審閱的 PR/commit、採納的範圍和是否允許 M4。單獨開啟 Codex 時以該審批 ref 為準。
- 獲准 M4 後以 `main` 的最新祖先及已批准方案為依據，建議 `implementation/marble-v0.2-android-mvp`，建議 Android 工程位於 `ideas/Marble/android/`。候選 PR 記錄變更、可重建命令、內容授權清單、證據路線和已知問題。草稿 PR 僅提交可公開的材料，家庭真機的辨識資訊、真實生日及簽章秘密不進公開倉庫。APK 交付管道與公開範圍依所有者授權。
- 所有者可在本次審批採納 M2、確認 M3，並在同一回覆中明確授權 M4。獲授權後只需一個 [Codex 主任務](CODEX-HANDOFF.md)。若只批准方案，主代理停在 M3。
- M4 實作證據提交後由所有者接受或要求返工，再進 M5 最終獨立驗收。所有者也可明確授權合併 M4/M5 報告流程，仍須各自保存實作者與獨立驗收證據。家庭試用、重要 PR 合併、對外發佈、額外成本與重大需求／架構變更分別需明確批准。M6 根據家庭驗收結果另決定迭代。
