# Marble V0.2 可点击交互原型

轻量静态网页，用来验证已授权的 V0.2 核心交互。不是正式 App，也不连接服务端、账户或儿童数据。

## 本地运行

1. 将本目录下载或检出到电脑。
2. 在本目录启动静态文件服务器：

   ```bash
   python -m http.server 8000
   ```

3. 在浏览器打开 `http://localhost:8000`。建议用移动设备浏览器或开发者工具的窄屏视口查看。

原型使用浏览器系统语音合成演示低龄整图点击播放；动物声音与照片通过 Wikimedia Commons 临时素材链接载入；雨水动画由本原型的 HTML/CSS 示意制作。首次加载需要网络。资源不可用时，页面保留文字说明并显示降级状态。所有示意素材均非 Marble 正式媒体。来源与许可见 [MEDIA-CREDITS.md](MEDIA-CREDITS.md)。

## 源码检查

```bash
node --check app.js
node validation/static-checks.js
```

这两项是 JavaScript 语法和源码结构检查，不代替动态浏览器或真机测试。当前没有实现语言切换；UX09 结果和环境限制见 [UX01-10-VALIDATION.md](UX01-10-VALIDATION.md)。阶段结论见 [MILESTONE-REPORT.md](MILESTONE-REPORT.md)。

## 操作路线

- 首页 →「滑滑认识世界」：上滑下一张、下滑上一张；点击整张照片调用本机系统语音。每组 5 张，滑到末张后显示重看、换组、回首页。
- 首页搜索「香蕉」「动物」「雨」：进入相应普通知识详情。详情上下滑动用于浏览内容。
- 香蕉详情 →「打开知识地图」→ 点「苹果」→ 左上返回：恢复香蕉为中心的地图。地图底部按钮返回原详情。
- 动物详情：分别点选鸟声或蛙声；切换时停止上一段。两段录音只是临时样本，不代表最终声音策略。
- 雨水详情：主动开始/暂停/重播动画，也可以按步骤看过程。
- 「和家长一起看」或详情里的「家长陪读」：打开陪读抽屉；打开时停止正在播放的声音，关闭后不会自动续播。
- 顶部可随时切换全局主题，切换后导航与知识内容不变。

## 内容边界

香蕉是 `local:banana-identification` 本地扩展示例，不是上游 Marble 节点。动物和雨水使用前期研究中的知识样板，仅作交互演示。图片、音频、系统朗读和动画均未完成正式内容审校、录制或发布。历史仅保存在本机浏览器 `localStorage`，可在家长入口查看与清除。

## 当前局限

- 未进行真实手机测试。桌面窄屏、浏览器自动化或触控模拟均不能证明真机尺寸、误触或不同浏览器语音表现。
- 外部照片与录音需要联网；加载失败时会出现文字降级。纯 CSS 动画在减少动态效果的设备设置下保持静止。
- 本阶段不含 Android、数据库、账号、后台、正式语音识别、识图、云端问答或批量知识内容。
