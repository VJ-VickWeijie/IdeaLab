# 原型制作前多角色评审

日期：2026-11-17。范围：只评审已批准的 V0.2 核心操作如何做成可验证原型，不重新讨论愿景、森林主题或低龄地图扩展。

## 角色与执行方式

| 角色 | 任务 | 实际上下文 / 模型限制 |
|---|---|---|
| 协调者与前端原型工程师 | 统筹基线、实现交互、运行本地检查 | 当前 Work 会话；未提供按角色切换模型的能力 |
| 产品与 UX 设计师 | 单独识别页面/手势/返回/声音冲突，提出交互断言 | 独立代理上下文；实际模型标识不可见 |
| 儿童体验与教育内容研究员 | 独立检查年龄适配、亲子讲解、媒介与安全文案 | 独立代理上下文；实际模型标识不可见 |
| 独立验收员 | 原型完成后隔离检查文件和可复现实测 | 由另一个独立代理上下文承担，不参与实现 |

两个预制作评审代理分别给出建议，协调者合并。没有声称角色使用了不同型号或真实用户/儿童参与评估。

## 讨论要点与取舍

| 主题 | 观察 / 不同意见 | 本轮选择及理由 |
|---|---|---|
| 连续认知的点击与滑动 | 纵向手势与图片点击可能在一次触控中同时成立 | 仅在独立连续认知页识别垂直滑动；超过阈值即取消点击。单击整图才调用系统语音；切换先停旧声音。详情页不注册该手势，保持普通滚动。 |
| 放大照片 | 复用图片单击会和已确认的播放热区冲突 | 使用照片下方单独的放大入口；不叠放独立显著播放键。 |
| 动物声音 | 研究确认声音是内容媒介，但尚未确定播放规则 | 采用主动点选独立声音卡片；同时只允许一个声音播放，切换停止前一段。明确标为原型假设。 |
| 雨水过程 | 研究认为水坑/水循环适合展示变化；是否自动播放/节点点选仍待定 | 用户主动开始，可暂停、重播并按步骤看；这是用于比较的原型假设，不形成全局规则。 |
| 家长陪读抽屉与声音 | 抽屉会遮挡页面；原规范要求验证是否暂停 | 打开时停止所有音频，关闭后不自动续播，避免抽屉遮挡时意外继续发声。保留状态提示供实测。 |
| 香蕉现实探索 | 较早研究 JSON 曾有更严的临时限制；最新项目 README / 产品决策允许适龄看、轻触、闻，已知过敏用短提示 | 依最新确认决策呈现“看、轻触果皮、闻自然香味”；不要求品尝或回答，已知过敏时改看照片。该样板仍是本地扩展且待内容人工审查。 |
| 低龄地图 | 交接已确定当前节点 + 2–3 个大图节点，扩展暂缓 | 香蕉/苹果为中心时，各保留三个相关节点（植物、相似水果、生长等）；不加缩放、分页或新增扩展玩法。 |

## 哪些问题必须靠原型

整图单击和快速滑动是否冲突、手势阈值、音频被新页面/抽屉中断、家长抽屉遮挡、地图往返状态、主题在多屏一致、搜索/历史操作，以及媒体加载失败后的降级，都需要实际交互。真实设备触控面积和真实幼儿可用性必须另在真机/目标年龄家长陪同下验证；桌面视口不能代替。

## 保留给产品所有者

动物声音知识的正式播放入口与是否可自动连播；雨水动画的默认启动方式以及是否允许点击具体过程节点深入，仍须审批。本轮只给出方便比较的主动操作假设。
