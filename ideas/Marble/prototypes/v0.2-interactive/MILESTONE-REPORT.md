## 已完成

- 轻量静态网页：0–2 首页、有限连续认知、普通知识详情、家长陪读抽屉、知识地图。
- 样板覆盖香蕉识别、动物交流声音比较、雨水因果过程，并标出本地扩展、上游样板与临时媒体的边界。
- 连续认知 5 张一组、整图点击朗读、角落半透明提示、纵向切卡不自动朗读、末项结束选择、单独放大入口。
- 地图到普通详情与返回入口、知识搜索与历史、主题全局切换；本机无账号历史可清除。
- 来源与许可记录、原型运行说明、评审记录、偏差与风险、UX01–UX10 验证表。
- 主要操作控件 CSS 尺寸按 56 px 作为原型基线；真机实际 dp 和误触未验证。

## 实际验证与限制

- `node --check app.js` 通过；`node validation/static-checks.js` 的 20/20 源码断言通过。独立验收员复核了修复并认可源码状态；这些检查不覆盖动态交互。
- 本轮未获得原型页面的可访问浏览器预览。连接浏览器无法访问工作区 localhost；另一隔离浏览器拒绝本机路由并阻止 `file:` 协议导航。没有通过其他 UI 通道绕过限制。
- **UX01–UX08、UX10：未验证**；UX09：搜索与历史有源码实现，但语言切换缺失，当前项失败。具体逐项步骤、预期、实际、证据见 `UX01-10-VALIDATION.md`。
- **真实手机、目标 Android WebView、系统声音输出及儿童/家长观察均未完成。**
