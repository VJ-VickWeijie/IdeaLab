# 偏差、遗留问题与下一阶段建议

## 相对已确认设计的原型偏差

- 五屏是同一轻量网页中的页面状态，不是像素级还原稿；原五屏 PNG 是视觉方向参照，不代表本原型逐像素匹配。
- 低龄首页加入文字搜索和主题选择便于验证全局一致性；家长历史入口只存本机浏览器。
- 连续认知一组固定 5 项；设置了上/下按钮作为触控模拟和键盘可达辅助，不替代滑动规则。
- 地图节点用大圆形图标和关系线示意，不含正式知识关系 Schema，也没有高龄拖动/缩放。
- 地图关联节点目前以 emoji 插画图标表现；是否满足五屏视觉规范中的“大型图片节点”需要通过原型页面截图与视觉稿对照，不能仅凭源码验收。
- 动物声音采用独立声音卡片，主动点选且不自动连播；雨水使用手动开始/暂停/重播与步骤卡。这些是供比较的原型假设，并非批准的播放规则。
- 源码中动物与雨水知识主题使用研究样板标识；香蕉、苹果、植物和生长为本地示例，不能当作上游正式节点。
- 语言切换未实现。待定义 UI 语言、字幕/口述语言、方言语音、资源不可用时的回退顺序后，再决定范围。

## 风险和待办

1. **动态验证受限**：本轮连接浏览器无法到达工作区本地预览，`file:` 导航又被安全策略拒绝。现有结果不得标成浏览器/真机交互通过。使用 README 本地步骤在可访问的浏览器中完成 UX01–UX10。
2. **真机和儿童使用**：在目标 Android 机型核对真实 dp、系统安全区、返回手势、低龄误触和不同 WebView 行为；之后在家长陪同下观察，不要求幼儿答题。
3. **动物声音规则待批**：决定播放入口、单段长度/循环、是否允许连续比较，以及声音与解释文字的关系。
4. **雨水动画规则待批**：决定默认静止/主动播放/逐步点选；当前自动走到终态的示意只为原型假设，不应直接进入正式内容。
5. **语言策略待定义**：决定简体/繁体、粤语、英语各自作用于界面、字幕还是语音；本原型没有模拟切换。
6. **内容和媒体验收**：校验研究节点 ID、年龄、事实、音频/动画语义；替换临时 Commons 照片/录音前再次核对文件署名和许可。香蕉本地扩展示例需单独审校。
7. **可访问性与无障碍**：后续检查屏幕阅读器顺序、键盘焦点、动画减少设置、系统语音实际声线及对比度。
8. **外部媒体依赖**：照片和动物录音从 Wikimedia Commons 在线加载；脱网或来源变更时会降级为可读文字/图标，不提供离线媒体包。

## 建议的下一步

1. 在本地桌面/手机用 README 启动网页，由产品与 UX 完成 UX01–UX10 真实浏览器操作并保存屏幕证据。
2. 先由产品所有者决定语言切换、动物声音、雨水动画三个策略，再做小范围修订。
3. 做一次目标手机 WebView 的真机检查。复核点击整图、52 px 滑动阈值、放大入口、系统返回、抽屉滚动和语音中断。
4. 关闭本轮 UX 问题并由独立审查员复验后，再提交原型阶段总结供人工审批。之后如要启动 Android/服务端开发，另行审批。
