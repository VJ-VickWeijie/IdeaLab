## 抽样与验证结果

按覆盖目标有目的地固定 30 个真实 ID，无随机过程。科学取 12 条，以便对照雨、水循环、雷暴、动物、工具、材料、生物和证据等类型并覆盖安全边界；其余学科取 1–3 条，检验同一编排结构能否处理语音、历史证据、文化视角、数学表征、隐私和生活技能。该分配适合发现结构缺口，分类准确率需由留出样本另行验证。

| 验收项 | 实际证据和限制 |
| --- | --- |
| 上游真实性与溯源 | 快照 1,912 个唯一节点、4,002 条依赖。两份原始 JSON 的字节数、SHA-256 与清单一致。30/30 名称、学科、领域、类型、原版年龄与原始描述哈希匹配。Animal Communication 和 Rain & Puddles 在列。 |
| 样本覆盖 | 12/12 学科、5/5 原版类型、9/9 主体验标签、8 种首选媒介，28 条使用多标签。17 条从现象切入，13 条从提问切入。30 条都有可选关联，其中 1 条经原版依赖核对，29 条属于本地关联。 |
| 年龄 | 原版最早从 3 岁开始。3–6、6–9、9–12 分段分别与 14、24、22 个样本原版年龄范围相交，同一节点可落入多段。原版样本的局部适配覆盖 1–2 至 9–12 五段，0–1 岁通过独立香蕉样板补证。原版年龄与本地呈现年龄分别存储。 |
| 结构与离线替代 | 30/30 原版加 1/1 香蕉通过 Schema 和数据一致性检查。10/10 Schema 变异均被拒绝。样本实际提供离线文字，所有外部媒介处于拟议或缺位状态。听辨、触觉和工具动作无法通过文字验证。 |
| 分类独立盲标 | 独立审查者在查看作者标签前锁定八项主标签与可接受备选；主标签 8/8 一致。作者侧未做盲法约束，也没有人工金标准。该指标只表示八项的一致度。 |
| 活动元数据 | 30 条中 16 条有低风险活动、1 条有中风险活动、13 条为空。现实活动均带可选性、监护、环境前提、风险和离线替代。雷暴、风暴安全和手锯仅保留模拟体验。 |
| 规则模拟与人工队列 | 71/71 合成场景得到预期裁决、原因及路由。31 硬阻断、30 安全回退、3 转人工、7 个安全对照模拟放行。样本另有 15 个原版节点和香蕉进入内容人工复核。详见机器日志。 |

## 主要判断与返工

- **类型、媒介与安全可分别表达。** 动物交流适合用声音和图片比较信号；水坑适合看随时间的变化；香蕉适合实拍辨识；历史和数学可用同一结构呈现证据和模型。标签允许多角度。听辨节点的文字只能提供概念入口，需要合适音轨才能验证原目标。
- **离线预处理最适合先做 100 节点基线。** PC 离线生成候选并交审，NAS 存放带版本的已审内容，App 用本地规则选择体验。反对意见集中在长尾、周更审核积压和粤语检索。下一轮可独立比较运行时生成，以及只允许从已审 ID 里动态排序的混合模式。实际延迟、成本、设备容量和模型质量均待测。
- **高风险设计须分开处理文案与活动资格。** 模拟器使用固定动作、场所和独立可信上下文。独立复核发现天气字段矛盾时可能误放行，已修复并以 WX19／WX20 复测。审核还调整了食品、画具、隐私、化石和香蕉文案，使演示、想象和物品接触各自适用明确的前提。实际样本文案与白名单模板的运行时绑定仍未验证，合成结果不能授权儿童活动。
- **存在事实与文化争议的内容继续留在队列。** 例如凑 9 的原版标题同简介的凑 10 范例冲突；溶解样板区分溶液与可见颗粒时需维持「溶液是混合物」的关系；First Nations／Country 案例需对应相关社群和认可资料；法语可提供文本概念，实际辨音需审校目标变体与录音。原版资料保留独立，不覆盖原文。

## AI-Workflow 与审批

| 工作 | 执行方式 |
| --- | --- |
| M0–M3 目标、评审、设计和计划 | IdeaLab 研究授权覆盖这些步骤和本轮执行。协调者以分类、媒介、风险和原版来源建立分层名单。方案讨论比较本地预处理、实时生成和受限混合。 |
| M4 样本和实验 | 协调者、两批内容研究、Schema 设计、安全研究与架构研究分工。Work/Codex 的并行 GPT-6 系列上下文处理专业判断，Python 执行固定数据、Schema 与安全回归；角色未指定型号覆盖，无可靠子型号或逐角色成本计量。 |
| M5 独立验收 | 执行者先复跑校验；独立审查上下文复核源事实、风险和内容，重跑规则并保留盲标和修复证据。儿童使用体验、真实世界信号及人工内容审批留待验证。 |
| M6 交付 | 当前 PR 提交研究证据，等待所有者选择批准本轮并授权下一步、要求修改重审、继续暂停或终止。审批结果和范围在获得决定后另记。 |
