# Marble｜儿童成长型知识探索项目

面向约 0–12 岁儿童的成长型知识探索伙伴。以互相关联的知识节点为基础，根据儿童年龄、理解能力和提问兴趣，提供简短直接的回答、亲子提示、知识卡片、过程动画及自主探索。**当前优先建设知识图谱、中文目录和分龄内容规范；尚未启动 App 开发。**

## 已确认的产品原则

- **一张知识网络，多种年龄呈现**：0–1 岁感官命名和亲子陪伴；1–2 岁感受、回应与重复；2–3 岁简单关联；3–6 岁亲切卡通和恰当比喻；6–9 岁自主探索关系；9–12 岁更深入的多因素与跨领域探索。
- **先回答，再拓展**：默认简短直接回答，按孩子追问逐层展开；低龄阶段不强制反问或测验；9–12 岁系统主动开放性反问仅用于少量合适场景（约 3–5%）。
- **按知识类型选择呈现**：例如落雨用过程动画、石头与气球用对比卡/短动画、香蕉识别优先实物照片；不强制所有知识写成故事。
- **正式内容的双语规范**：粤语配音、粤语口语字幕、英文字幕及独立完整英文配音；即时问答默认粤语，可按需补充英文关键词。
- **科学准确性优先**：拟人化及比喻必须避免造成科学误解；保留来源与事实核查记录。

## 真正待确认或待完成的事项

以下不应与已经确认的全局原则混淆：

1. **样板最终定稿**：2–3 岁「落雨」独立提示卡仍是草案；6–9 岁和 9–12 岁的具体样板尚未逐项审批。年龄段原则已确认，**不等于每张样板已审批**。
2. **交互细节**：动画默认完整观看，还是提供可选点击知识节点，尚未最终决定。
3. **内容技术规范**：统一知识节点 Schema、上游 ID 映射、动态知识连接验证、科学审校流程及批量媒体生产尚未完成。
4. **译文质量**：中英目录已覆盖全部 1,912 个节点，但仍含机器初译及待复核内容；原文个别标题与简介不一致，不能擅自改写上游。

**当前不需要为继续整理目录再次征求用户确认。** 只有涉及尚未批准的产品交互、样板定稿或重大架构取舍时，才需要单独确认。
