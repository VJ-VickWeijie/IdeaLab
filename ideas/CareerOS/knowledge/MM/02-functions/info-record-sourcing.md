# MM-03｜采购信息记录与货源决定

> 状态：drafting｜M4 批次 A｜目标版本 SAP S/4HANA 2021 On-Premise。正文只陈述 SAP S/4HANA 2021 Feature Scope Description 明确支持的功能范围；不将高层功能说明扩展为具体客户的 MRP 选择顺序、有效期字段规则或配置结果。

## 为什么采购要维护货源信息

同一种材料可能有多个供应商、合同或长期供货安排。业务需要回答两个不同问题：

1. **哪些来源可以考虑？**
2. **某项需求要如何分配给来源？**

采购信息记录、货源清单和配额安排分别承载不同信息，不能互相替代。SAP S/4HANA 2021 的功能范围文件把它们放在 Source Assignment（货源分配）能力中，并说明其目标是识别潜在供应来源；该版本列举采购信息记录、货源清单、配额安排、询价和供应商报价等相关功能。

## 三类对象各自解决什么问题

| 对象 | 入门理解 | SAP S/4HANA 2021 来源明确支持的内容 | 本篇不据此推断 |
| --- | --- | --- | --- |
| **采购信息记录**（Purchasing Info Record，PIR） | 记录特定材料与供应商之间的采购信息。 | 可包含特定材料向特定供应商采购时使用的价格和条件；条件变化可被查看/分析。供应商与材料信息可按采购组织或工厂级别保存；来源列出 standard、subcontracting、pipeline、consignment 等采购类型。还可标记信息记录，使其在 MRP 自动创建采购申请时纳入考虑。 | 不表示只要存在信息记录，MRP 就必然选择该供应商；不推断各类字段、有效期和组织层级之外的客户配置。 |
| **货源清单**（Source List） | 记录可供特定材料/工厂使用的供应来源信息。 | 来源说明货源清单可定义哪些供应来源在 MRP 中可用；视材料或工厂，可用于自动分配信息记录、计划协议项目或采购合同项目作为来源。 | 不将其描述为所有采购场景的必需清单；不据高层说明推导来源优先级、固定来源、封锁指示或有效期字段的算法。 |
| **配额安排**（Quota Arrangement） | 表达某工厂的一项材料需求如何分配到多个供应来源。 | 2021 文件说明配额安排可将某工厂对某材料的需求拆分给多个来源（例如多个供应商），以降低重要材料交付失败风险。 | 不展开配额评分、计算公式、基准数量、上限数量、来源淘汰规则或精确分配结果；这些需要对应版本的详细来源。 |

### 先把“供应商资料”和“货源决定”分开

MM-02 讲的是物料主数据和供应商 BP 的基础模型。MM-03 往前一步，说明采购怎样记录“特定材料—供应商”的关系、哪些来源在 MRP 场景中可用，以及需求是否由多个来源分担。

- 供应商 BP 说明业务伙伴是谁。
- 采购信息记录说明某个供应商与某种材料之间有哪些采购信息。
- 货源清单和配额安排是货源决定相关对象，不是 BP 的通用数据。
- PR/PO 是采购需求和采购约定单据；如何创建、审批、决定来源和后续处理，留到 MM-04 与 PROCESS 文章。

同一供应商可以涉及不同材料；同一材料也可能与多个来源有关。这个对象关系是概念模型，不等于客户系统中完整的记录基数、字段键或自动选择规则。

## 一个离线学习例子

虚构工厂“广州 Plant”要采购材料 M-100（包装材料），采购团队已有供应商 V-A 和 V-B：

1. **先看材料与供应商分别是谁。** M-100 的材料主数据由 MM-02 讲解；V-A、V-B 的业务伙伴身份也由 MM-02 讲解。
2. **看是否记录了材料—供应商采购信息。** 采购信息记录用于保存 M-100 与某供应商相关的采购条件信息。它不等同于一张采购订单。
3. **看 MRP 场景有哪些来源可用。** 货源清单可表达 MRP 所用的可用来源，并可在来源描述支持的条件下参与自动分配。
4. **看需求是否要由多个来源分担。** 如果业务希望把 M-100 的某工厂需求分给 V-A 和 V-B，配额安排提供了表达这种分配意图的对象。

以上是功能关系的虚构说明。例子不设定百分比、不演示自动选择、不假设来源记录一定有效，也不表示每家公司都需要同时维护三类对象。目标版功能范围支持它们各自的用途，但未给出可用于推导任一客户自动选择结果的完整算法。

## 从需求到货源：可先理解的高层关系

可以用下面的学习框架组织采购思路：

1. 业务或计划产生某材料的采购需求；S/4HANA 2021 文件说明 PR 可以人工创建，也可能由 MRP 需求形成。
2. 采购需要识别可考虑的供应来源。文件列出采购信息记录、长期采购协议、货源清单及配额安排等相关来源管理能力。
3. 货源清单可在 MRP 场景中指出可用来源，并可用于自动分配其支持的来源对象；信息记录也可以被标记为在 MRP 自动生成 PR 时纳入考虑。
4. 配额安排解决多个来源分担特定材料/工厂需求的功能需求。
5. 如果当前没有有效来源，S/4HANA 2021 功能范围还列出 RFQ（Request for Quotation，询价）能力，供采购向供应商询价并寻找来源。

此处是**功能关系框架，不是系统执行顺序**。步骤编号只用于学习者理解对象之间的业务问题，不代表 SAP 系统按 1→5 顺序查表，也不代表任何来源必然自动落入 PR 或 PO。

## 价格与来源选择是相关但不同的问题

采购信息记录可保存特定材料/供应商关系下的价格与条件信息；货源清单和配额安排则服务于来源可用性/需求分担等问题。学习时不要把“存在价格”直接等同于“来源一定被选中”，也不要把“可作为来源”直接等同于“本次采购价格已最终确定”。价格条件如何复制到 PR/PO、合同如何被调用、来源优先级和价格确定的完整规则，不在当前 2021 高层来源范围内；请分别到 MM-04、PROCESS-01 及后续经核验的专篇学习。

## 需要详细版本资料后才能说明的细节

当前直接核对的 SAP S/4HANA 2021 Feature Scope Description 支持三类对象的主要用途，但不覆盖完整 customizing 和算法。本篇不提供以下确定规则：

- 采购信息记录、货源清单、配额安排在所有手工 PR、MRP PR 和 PO 场景中的固定优先级；
- source list 的具体有效起止日期字段、边界日期处理及固定/封锁指示的优先级；
- quota rating、quota base quantity、maximum quantity 等精确计算和取舍规则；
- source list 要求开关、material/PIR 具体指示与客户 MRP 配置的完整组合；
- 事务码、IMG 路径、数据库表/键、API、字段默认或客户系统权限；
- PR/PO 如何复制来源、价格、合同信息，以及不同单据类型、采购类型、异常状态下的结果。

这些不是“系统没有规则”，而是本篇所用固定版高层来源没有展开。需要针对某个具体规则另找 SAP S/4HANA 2021 On-Premise 直接文档，再决定是否补入本篇或拆为后续专题；不能用更新版本、其他 SAP 产品线或 ECC 的算法替代。

## 只读练习

不需要登录 SAP。请对下面的虚构问题写出“对象—它回答的问题—还缺什么证据”：

- 计划员要为 M-100 的广州 Plant 补充采购来源。
- M-100 与 V-A 有一条信息记录，M-100 与 V-B 也有一条信息记录。
- 采购团队希望 V-A 与 V-B 都可供 MRP 考虑，并希望将部分需求分配给两家。

建议答案应区分：信息记录表达材料—供应商采购信息；货源清单承担 MRP 来源可用性的相关管理功能；配额安排表达将特定材料/工厂需求分给多个来源。需要回答“本次实际会选谁、比例是多少、记录何时生效”时，必须继续核对目标版详细规则，而不是仅凭对象名称推断。
