# MM-03｜采购信息记录与货源决定

> 状态：reviewed（16 个有效闭环：普通读者 5、资深 SAP 配置顾问 6、普通 SAP 开发人员 5；待所有者验收）｜M4 批次 A｜目标产品版本 SAP S/4HANA 2021 On-Premise。本文依据 SAP S/4HANA 2021 Feature Scope Description 文档版本 11.0（2021 SPS10，2026-07-22）所支持的高层功能范围；官方 PDF 使用动态 latest 链接，Work 于 2026-11-26 读取该版本。不将功能范围扩展为具体客户的 MRP 选择顺序、有效期字段规则或配置结果。

## 为什么采购要维护货源信息

同一种材料可能有多个供应商、合同或长期供货安排。业务需要回答两个不同问题：

1. **哪些来源可以考虑？**
2. **某项需求要如何分配给来源？**

采购信息记录、货源清单和配额安排解决的问题不同，不要把它们当成同一对象。是否要同时维护、某一对象是否足以满足特定业务流程，取决于场景和配置；本篇不声称系统强制要求三者并存。SAP S/4HANA 2021 的功能范围文件把它们放在 Source Assignment（货源分配）能力中，并说明其目标是基于过往采购订单和已有长期采购协议识别潜在供应来源；该版本列举采购信息记录、货源清单、配额安排、询价和供应商报价等相关功能。

## 三类对象各自解决什么问题

| 对象 | 入门理解 | SAP S/4HANA 2021 来源明确支持的内容 | 本篇不据此推断 |
| --- | --- | --- | --- |
| **采购信息记录**（Purchasing Info Record，PIR） | 记录特定材料与供应商之间的采购信息。 | 可包含特定材料向特定供应商采购时使用的价格和条件；条件变化可被查看/分析。供应商与材料信息可按采购组织或工厂级别保存；来源列出 standard、subcontracting、pipeline、consignment 等采购类型。还可标记信息记录，使其在 MRP 自动创建采购申请时纳入考虑。 | 不表示只要存在信息记录，MRP 就必然选择该供应商；不推断各类字段、有效期和组织层级之外的客户配置。 |
| **货源清单**（Source List） | 记录可供特定材料/工厂使用的供应来源信息。 | 来源说明货源清单可定义哪些供应来源在 MRP 中可用；视材料或工厂，可用于自动分配信息记录、计划协议项目或采购合同项目作为来源。 | 不将其描述为所有采购场景的必需清单；不据高层说明推导来源优先级、控制指示含义或有效期字段规则。 |
| **配额安排**（Quota Arrangement） | 表达某工厂的一项材料需求如何分配到多个供应来源。 | 2021 文件说明配额安排可将某工厂对某材料的需求拆分给多个来源（例如多个供应商），以降低重要材料交付失败风险。 | 不展开配额评分、计算公式、基准数量、上限数量、来源淘汰规则或精确分配结果；这些需要对应版本的详细来源。 |

### 四种表述不是同一状态，也不表示执行顺序

| 说法 | 2021 文档支持的入门解释 | 不能据此推出 |
| --- | --- | --- |
| **纳入 MRP 考虑** | 信息记录可以设置为在 MRP 自动创建 PR 时纳入考虑。 | 不能据此保证该信息记录一定成为本次需求的来源。 |
| **MRP 中可用** | 货源清单可用于定义哪些供应来源在 MRP 场景中有效/可用。 | “可用”不等于在所有需求中都会被选中，也不等于所有候选来源都已排序。 |
| **自动分配** | 货源清单可按材料或工厂参与自动分配信息记录、计划协议项目或合同项目作为来源。 | 功能范围没有给出完整触发顺序、优先级或所有配置条件。 |
| **分配到某条 PR** | PR 可从建议来源中分配来源，也可以人工指定供应商。 | 对一条 PR 的结果不能只凭某条信息记录或清单存在而推断。 |

表格把来源文档中的不同表达分开解释；它不是流程图，也不声称这些动作构成唯一的先后顺序。

### 先把“供应商资料”和“货源决定”分开

MM-02 讲的是物料主数据和供应商 BP 的基础模型。MM-03 往前一步，说明采购怎样记录“特定材料—供应商”的关系、哪些来源在 MRP 场景中可用，以及需求是否由多个来源分担。

- 供应商 BP 说明业务伙伴是谁。
- 采购信息记录说明某个供应商与某种材料之间有哪些采购信息。
- 货源清单和配额安排是货源决定相关对象，不是 BP 的通用数据。
- PR/PO 是采购需求和采购约定单据；如何创建、审批、决定来源和后续处理，留到 MM-04 与 PROCESS 文章。

同一供应商可以涉及不同材料；同一材料也可能与多个来源有关。这个对象关系是概念模型，不等于客户系统中完整的记录基数、字段键或自动选择规则。

## 一个离线学习例子

虚构工厂“广州 Plant”要采购材料 M-100（包装材料），采购团队已有供应商 V-A 和 V-B：

1. **先看材料与供应商分别是谁。** M-100 的材料主数据由 MM-02 讲解；V-A、V-B 的业务伙伴身份也由 MM-02 讲解。
2. **看是否记录了材料—供应商采购信息。** 采购信息记录用于保存 M-100 与某供应商相关的采购条件信息。它不等同于一张采购订单。
3. **看 MRP 场景有哪些来源可用。** 货源清单可表达 MRP 所用的可用来源，并可在来源描述支持的条件下参与自动分配。
4. **看需求是否要由多个来源分担。** 如果业务希望把 M-100 的某工厂需求分给 V-A 和 V-B，配额安排提供了表达这种分配意图的对象。

   **业务概念例子（非 SAP 计算）：** 企业对 M-100 有 100 件需求，采购团队的业务意图是大约 60 件向 V-A 采购、40 件向 V-B 采购。这只演示“把需求分给两家”的想法，不是 SAP 字段值、配额计算结果或系统保证的数量比例；具体分配规则仍须查目标版详细资料。

以上是功能关系的虚构说明。60/40 仅作为业务意图的示例，不代表 SAP 的计算或执行结果；例子也不演示自动选择、不假设来源记录一定有效，并不表示每家公司都需要同时维护三类对象。目标版功能范围支持它们各自的用途，但未给出可用于推导任一客户自动选择结果的完整算法。

## 货源决定的概念地图：用问题理解对象，而非还原系统步骤

阅读这一主题时，可按下面的问题整理概念：

- **需求是什么？** SAP S/4HANA 2021 文件说明采购申请可以人工创建，MRP 需求也可能产生采购申请。
- **哪些对象可提供采购信息？** 采购信息记录关联特定材料和供应商；长期采购协议也属于来源分配相关能力。
- **哪些来源可用于 MRP？** 货源清单可用于表达 MRP 中可用的来源，并在文档描述的场景中参与自动分配。
- **一个工厂的材料需求是否要分给多个来源？** 配额安排支持把特定材料/工厂需求分给多个来源。
- **当前没有合适来源怎么办？** Source Assignment 章节说明可用 RFQ 寻找来源；Requirements Processing 章节还提到没有来源或存在多个潜在来源时，可以创建 RFQ 寻找合适供应商。

以上是**供学习者组织问题的概念地图**，不是 SAP 执行步骤、来源检查优先级或单据状态转换顺序。实际 PR 上可以从建议来源中分配来源，也可以人工指定供应商；是否自动分配、具体来源是什么，不能仅凭本篇列出的对象推断。

## 价格与来源选择是相关但不同的问题

采购信息记录可保存特定材料/供应商关系下的价格与条件信息；货源清单和配额安排则服务于来源可用性/需求分担等问题。学习时不要把“存在价格”直接等同于“来源一定被选中”，也不要把“可作为来源”直接等同于“本次采购价格已最终确定”。价格条件如何复制到 PR/PO、合同如何被调用、来源优先级和价格确定的完整规则，不在当前 2021 高层来源范围内；请分别到 MM-04、PROCESS-01 及后续经核验的专篇学习。

## 需要详细版本资料后才能说明的细节

当前直接核对的 SAP S/4HANA 2021 Feature Scope Description 支持三类对象的主要用途，但不覆盖完整 customizing 和算法。本篇不提供以下确定规则：

- 采购信息记录、货源清单、配额安排在所有手工 PR、MRP PR 和 PO 场景中的固定优先级；
- source list 的具体有效起止日期字段、边界日期处理及固定/封锁指示的优先级；
- quota rating、quota base quantity、maximum quantity 等精确计算和取舍规则；
- source list 要求开关、material/PIR 具体指示与客户 MRP 配置的完整组合；
- 事务码、IMG 路径、数据库表/键、API、字段默认或客户系统权限；
- PR/PO 如何复制来源、价格、合同信息，以及不同单据类型、采购类型、异常状态下的结果。

这些不是“系统没有规则”，而是本篇所用的 SAP S/4HANA 2021 产品文档高层功能范围没有展开。需针对具体规则另找可复核的 S/4HANA 2021 On-Premise 详细资料，再决定是否补入本篇或拆为后续专题；不能用更新版本、其他 SAP 产品线或 ECC 的算法替代。

## 只读练习

不需要登录 SAP。请对下面的虚构问题写出“对象—它回答的问题—还缺什么证据”：

- 计划员要为 M-100 的广州 Plant 补充采购来源。
- M-100 与 V-A 有一条信息记录，M-100 与 V-B 也有一条信息记录。
- 采购团队希望 V-A 与 V-B 都可供 MRP 考虑，并希望将部分需求分配给两家。

建议答案应区分：信息记录表达材料—供应商采购信息；货源清单承担 MRP 来源可用性的相关管理功能；配额安排表达将特定材料/工厂需求分给多个来源。需要回答“本次实际会选谁、比例是多少、记录何时生效”时，必须继续核对目标版详细规则，而不是仅凭对象名称推断。
