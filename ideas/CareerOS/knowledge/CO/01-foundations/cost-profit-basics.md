# 管理会计从零：成本与利润

> 本篇承接 FI-01～FI-03。先抓住两个问题：**财务会计（Financial Accounting，FI）关注业务金额如何进入财务核算与报表；管理会计（Controlling，CO）帮助管理者按成本对象观察成本、计划和实际。**S/4HANA 2021 的官方资料描述了二者相关的报告数据背景，但业务处理目标和规则不能因此混为一谈。[E1][E2]

## 1. 企业为什么要看成本

只知道“本月花了多少钱”不够。管理者还会问：这笔成本属于哪个部门或活动？实际数与计划差多少？偏差来自数量、价格、时间还是业务安排？下一步需要核对哪些业务信息？

| 观察角度 | 入门问题 | 例子 |
| --- | --- | --- |
| FI / 总账（General Ledger） | 金额在什么期间、哪些财务科目和报表口径中体现？ | 财务人员查看某期间的费用及损益表 |
| CO / 管理分析 | 成本归在哪个管理对象？计划与实际有什么差异？ | 部门负责人查看本部门成本中心的计划、实际和差异 |

这是入门的“问题视角”，不是把 FI 与 CO 划成互不相通的数据岛。SAP 2021 的 General Ledger 产品说明将总账与财务会计关联；同一产品资料说明 Universal Journal 支持相关内外部核算报告，并且 FI、CO 等业务活动仍有各自处理任务。[E1][E2]

## 2. 用一笔虚构费用看两种视角

假设 IT 部门本月有 50,000 元软件服务费用。本例只讨论管理问题，先假定：

1. 费用已按企业自己的业务流程确认并记录；
2. 本例实际金额已归到 IT 部门对应的成本中心；
3. 可比较的计划金额为 45,000 元。

这些是教学假设，不表示 SAP 会自动确认费用、分配成本中心或准备计划数据。

- **FI 角度：**关心费用属于哪个期间、按什么财务核算口径报告。SAP 2021 总账范围涵盖财务核算、日记账与损益表等内容。[E1]
- **CO 角度：**在相同期间和观察范围内比较成本中心实际 50,000 元与计划 45,000 元。本例差额为 5,000 元。SAP 2021 功能范围支持对成本中心等对象按选定期间报告 actual 与 plan。[E3]
- **管理追问：**超出的 5,000 元是新增用户、单价变化还是服务期限变化？差额本身不能解释原因，还要结合合同、数量和业务说明。

本例是普通算术，没有展示 SAP 凭证或过账步骤；不由此推导借贷方向、税额、自动科目决定或采购分录。普通库存采购的完整借贷、税务及自动科目规则仍属于 FI-07 的开放边界。

## 3. 从零理解几个词

### 成本中心（Cost Center）

入门时，可以把成本中心想成一个**观察某个组织责任范围内成本的管理维度**。SAP S/4HANA 2021 的产品范围说明直接提到按成本中心捕捉成本，并支持成本中心的 actual/plan 报告。[E1][E3]

“部门成本中心”只是教学心智模型，不保证每家公司都按部门设置，也不说明每笔业务必然会分配到成本中心。能否分配、如何分配和使用哪些层级，需按业务场景与配置确认；本篇不推定具体设置。

同一份 SAP 2021 功能范围还把成本中心、内部订单（Internal Order）和项目分别列为成本会计主数据类别。[E1] 入门时先把内部订单当作与成本中心不同的管理对象；该列表没有完整定义两者的使用规则。本篇不判断真实/统计订单、适用场景、接收方或结算条件，这些留给 CO-03 的目标版研究。

### 计划、实际与差异

- **计划（Plan）：**事前用于比较的目标或估计。
- **实际（Actual）：**在相关范围内已记录、可用于报告的数值。
- **差异（Variance）：**在相同期间和观察范围中比较计划与实际得到的差额。

SAP 2021 产品范围说明支持按选定期间报告实际和计划数据；但它不能证明实际何时形成、计划如何准备、报表显示什么字段或计划值必然存在。[E3] 该功能范围还说明，统计关键指标（statistical key figures）可以作为期末分摊的基础。[E1] 这只说明产品范围中的一种用途，不给出指标选择、计算公式、接收对象或是否执行；本篇不推导具体分摊规则。

### 利润（Profit）与现金

入门练习可用“特定范围、特定期间的收入减成本”来理解利润。例如，假设某产品报告收入 100,000 元、相关成本 70,000 元，简化计算为 30,000 元。

这是教学算术，不是 SAP 的完整利润计算规则。报告范围、收入与成本确认口径、期间和配置都会影响具体结果；后续获利分析另有专篇。**利润也不等于银行账户中的现金余额**：利润按核算口径衡量经营结果，现金余额反映某时点持有的现金。本篇不把销售、收款、现金流和利润分析合并成一个事件。

## 4. FI 与 CO 如何联系

SAP S/4HANA 2021 On-Premise 的产品范围说明把 Universal Journal 描述为相关外部和内部核算报告的数据背景；同时分别列出总账、资产会计、Controlling、物料账等处理活动，并说明相关内外部核算数据持续协调。该说明还注明成本法获利分析的例外，因此不能简化成“所有 FI 与 CO 场景都完全相同”。[E1]

SAP《Simplification List for SAP S/4HANA 2021》§8.1 在 Initial Shipment、Feature Pack Stack 1 & 2 的转换背景下，描述内部与外部报告从共同 document store 读取数据、account 为共同要素的总体方向；它不是所有后续支持包中每个流程、字段或接口的完整规格。[E2]

初学时记住：

1. FI 与 CO 关注的问题不同，但可共同支持企业理解业务金额和资源消耗。
2. 目标版资料描述了 Universal Journal 的共享报告数据背景。
3. 报告数据共享不证明每个业务事件都自动生成两份独立凭证，也不证明 FI 与 CO 的配置、授权、字段或业务步骤完全一致。
4. 普通采购、库存估价、税和自动科目决定仍未在 FI-07 闭合；具体内部订单、分摊与结算留给各自文章。

## 5. 可选离线练习

某项目组本月计划费用 80,000 元，假设报告实际费用为 86,000 元。

1. 计划与实际相差多少？
2. 这个差额能说明项目为什么超支吗？
3. 负责人还需要查看哪些业务信息？
4. 为什么项目利润不能直接等同于账户现金余额？

**参考答案：**差额为 6,000 元；数字本身不能说明原因，还需调查范围、数量、价格和期间等业务信息；利润与现金余额采用不同观察口径。以上是教学计算，不代表 SAP 配置、过账或客户系统测试。
