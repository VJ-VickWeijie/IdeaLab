# QM-08｜质量检验数据模型：从一个 CDS 示例学会划定边界

> 状态：drafting｜M4 批次 A｜目标版本 SAP S/4HANA 2021 On-Premise。现有可读直接证据是 SAP S/4HANA 2021 FPS01 的一条结果属性 CDS 示例；它不能证明 SAP S/4HANA 2021 初始版可用、数据库表键/关联已核实，也不能证明 CDS 的 released API 状态或当前用户有访问权限。

## 本篇为什么很短

“数据模型”容易让人联想到表名、主键、外键、关联基数和接口契约。但这些结论都需要各自的目标版本来源。当前直接材料只提到检验结果属性 CDS view `I_INSPECTIONRESULTATTRIBUTE`，并把它放在一项 2021 FPS01 新比较符功能的描述里。因此本篇只教读者如何正确解释这条来源，不把一个 CDS 名称扩写成完整 QM 数据模型。

## 来源直接支持的关系

SAP《What's New in SAP S/4HANA 2021 FPS01》§4.3.8 描述检验结果属性的比较符变化：新增的 `≤` 与 `≥` 用来和 `<`、`>` 区分；为兼容已有数据，旧数据中的 `<` 仍表示“小于或等于”，`>` 仍表示“大于或等于”。来源还说，新增比较符在相应 Customizing 中增加条目后，会在不同结果记录应用及 `I_INSPECTIONRESULTATTRIBUTE` CDS view 中可用。该条目标注适用版本为 **SAP S/4HANA 2021 FPS01**。

这允许我们把来源中的**功能关系**概括为：

```text
FPS01 新比较符配置条目
          ↓
结果记录应用和指定 CDS view 可用这些新比较符
```

箭头只表示来源描述的功能前提与可用范围。它不是数据库 JOIN 图，也不是 CDS 字段映射或应用授权图。

| 问题 | 目前可直接回答的内容 |
| --- | --- |
| 被点名的对象是什么？ | 结果属性 CDS view `I_INSPECTIONRESULTATTRIBUTE`。 |
| 例子适用于什么版本？ | SAP 文档把该功能标为 SAP S/4HANA 2021 FPS01。 |

| 能否由此访问该视图？ | 不能；没有核验目标系统、视图发布状态、通信场景或当前用户授权。 |

## CDS 名称不等于表关系或 API 合同

本段没有列出物理表名、字段清单、主键、外键、关联方向、基数、过滤条件、行级权限或性能特征。也没有说明 `I_INSPECTIONRESULTATTRIBUTE` 是否在目标系统中以 released 状态开放给客户使用，或通过何种 API/通信场景发布。故本篇不提供示例 SQL、JOIN 条件或服务调用代码。

检查一篇数据模型资料时，应分别核对以下问题；一个答案不能替代另一个：

1. **存在性和版本**：资料是否明确适用于 2021 初始版、某 FPS，还是其他版本？
2. **语义**：文档怎样解释对象的业务含义？名称本身不能代替字段说明。
3. **技术定义**：字段、键、关联与基数是否来自该版本的定义或元数据？
4. **发布合同**：是否有目标版本 API/CDS 发布信息，以及访问方式和生命周期承诺？
5. **访问权**：目标系统是否启用该对象，当前账号是否获得相应授权？文档提及对象不代表这些条件成立。

这些是后续核验清单，不是对当前 QM 对象的事实陈述。

## 与其他质量对象的边界

检验批、检验特性、样本、结果、缺陷和使用决策都可能是质量学习中需要理解的对象，但当前来源段没有定义它们之间的表关系或事件顺序。不能从 `I_INSPECTIONRESULTATTRIBUTE` 这个名称推导它连接哪个检验批表、是否包含样本结果、如何标识检验特性，或一条结果能关联几个业务对象。对于这些主题，应等待固定 2021 版本的直接定义资料，再分别写入对应主张。

后续版本的 API 页面也不能代替 2021 证据。例如 M3 研究记录中的 2022 版 `API_INSPECTIONLOT_SRV` 线索属于后续版本；它不证明同一 API 在 S/4HANA 2021 已可用，也不排除 2021 存在其他接口。文章不以该线索作 2021 产品结论。

## 无系统连接时的阅读练习

读者只依据本文 SAP 固定版来源，尝试为以下结论标记“直接支持”或“证据不足”：

- 来源点名了哪个 CDS view？——直接支持。
- 新比较符与该 view 的关系是什么？——直接支持，限于 FPS01 §4.3.8 的描述。
- 该 view 的字段、主键和检验批关联是什么？——证据不足。
- 该 view 是否为 released API，当前用户是否能读取？——证据不足。
- 该 view 在 SAP S/4HANA 2021 初始版是否可用？——证据不足。

练习无需登录 SAP，也不要求执行 SQL 或调用生产接口。

## 文章状态与未闭合证据

现有来源只能支撑一个 FPS01 功能级 CDS 示例，尚不能完成“检验对象与数据模型”的核心学习目标。正文保持 `drafting`。要继续扩展，至少需要目标版本的 CDS 定义/发布目录、字段与键文档、对象间关联依据，以及相应授权/访问说明；未取得这些资料前，不补写表名、JOIN、API、可用性或用户权限结论。

未连接 SAP 系统；未查看 CDS 元数据、服务目录、PFCG 角色或客户系统状态，未做 SQL/API 实测。
