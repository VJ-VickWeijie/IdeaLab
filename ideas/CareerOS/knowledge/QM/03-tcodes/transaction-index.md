# QM-06｜QM 常用事务码导航：S/4HANA 2021 可核验条目

> 状态：drafting｜M4 批次 A｜目标版本 SAP S/4HANA 2021 On-Premise。本文仅整理 SAP 2021《Simplification List》明确列出的事务替代与授权对象说明，不是完整 QM 事务码目录；尚不能逐事务确认用户角色的显示/修改授权。

## 先把入口和授权分开

GUI 事务码、Fiori 应用和业务角色是不同概念。官方资料列出一个事务码或替代应用，只能证明该文档所述版本中的入口关系，不代表某个账号能打开它，也不代表当前系统启用了对应应用。

下表的版本边界是《Simplification List for SAP S/4HANA 2021》所注明的 Initial Shipment、FPS01、FPS02。它不证明其他 FPS、后续版本或客户系统的可用性。表中“显示”“创建”等词只转述来源对功能的描述，不是用户权限结论。

## 目标版来源明确列出的导航变化

| 对象/用途 | 事务码或应用 | SAP 2021 来源直接说明 | 权限与使用边界 |
| --- | --- | --- | --- |
| 检验结果记录工作清单 | `QE51` → `QE51N` | `QE51`（Results recording worklist）不再提供；来源列出 `QE51N` 作为替代。 | 这证明的是替代关系，不能据此推断 `QE51N` 的完整功能、显示模式或任何用户的结果录入权限。结果录入属于可能改变检验数据的操作；没有授权证据时不要在企业系统执行。 |
| 目录显示 | `QS45` → `QS42` | `QS45`（Display catalog）不再提供；来源列出 `QS42` 作为替代。 | “Display catalog”是来源中的功能标签，不证明 `QS42` 对当前账号只读，也不提供角色授权或具体目录对象范围。 |
| 抽样程序显示 | `QDV3`；对应 Fiori 应用 **Sampling Procedure** | 该应用取代 `QDV3` 在 Fiori Launchpad 中的导航；来源同时说明 `QDV3` 可直接调用。 | 直接可调用不等于当前用户有授权。来源没有逐用户角色、目录或只读授权数据。 |
| 采购质量信息记录显示 | `QI03`；对应 Fiori 应用 **Quality Info Records - Procurement** | 来源将该显示事务与对应 Fiori 应用并列，说明事务不在 Launchpad 中但可以直接调用。 | 不将该显示标题扩展为编辑权限判断；也不把“应用已集成到 QM Launchpad roles”理解为任一用户都获授权。 |
| 样品显示 | `QPR3`；对应 Fiori 应用 **Sample** | 来源列出 `QPR3`（Display sample）及替代 Fiori 应用，说明事务不在 Launchpad 中但可直接调用。 | 仅支持所列导航关系和显示用途。样品类别、客户角色或当前用户权限未核实。 |
| 检验方法版本显示 | `QS34`；对应 Fiori 应用 **Inspection Method** | 来源列出 `QS34`（Display inspection method version）及替代 Fiori 应用，说明事务不在 Launchpad 中但可直接调用。 | 来源未确认该应用在目标客户系统中的启用状态、用户目录或只读授权。 |
| 证书配置文件分配 | `QC11` → `QC15` | 来源将 `QC11` 标为创建证书配置文件分配，并列出替代事务 `QC15`。 | 创建属于变更型操作。此条仅记录来源中的替代关系，不建议在生产系统尝试；当前角色授权和字段级限制未知。 |
| 证书配置文件分配 | `QC12` → `QC16` | 来源将 `QC12` 标为更改证书配置文件分配，并列出替代事务 `QC16`。 | 更改属于变更型操作。来源不说明某角色可否使用，也不证明替代事务在客户系统中已启用。 |
| 证书配置文件分配 | `QC13` → `QC17` | 来源将 `QC13` 标为显示证书配置文件分配，并列出替代事务 `QC17`。 | “显示”不证明账号权限，也不代表替代事务只能读取。 |
| 证书配置文件分配（复制模板） | `QC14` → `QC18` | 来源将 `QC14` 标为以复制模型创建证书配置文件分配，并列出替代事务 `QC18`。 | 创建属于变更型操作。不能由事务名称推断复制范围、保存结果或授权。 |

来源还说明，表中部分替代 Fiori 应用已纳入 QM Launchpad 角色模板；这不是目标系统的用户授权清单。来源不提供上表每个事务码到具体业务角色、目录、组织范围或“只读”权限的逐项映射。因此本表的入口核验已按对象逐条记录，但权限核验仍未闭合。

## QM 授权资料能支持到哪里

同一版《Simplification List》另有 QM 授权对象迁移说明：部分旧授权对象没有 create/change 等活动字段，曾通过 `Q_TCODE` 校验事务码；S/4HANA 从 1709 起逐步增加含活动字段的新对象，文档说明新旧检查在该文档所述范围内并行有效。表中示例包括：

| 授权对象 | 2021 文档描述的操作范围 | 本文不推断 |
| --- | --- | --- |
| `Q_INSPLOT` | 编辑检验批 | 具体事务码映射、显示授权、检验批的客户组织范围 |
| `Q_INSPRSLT` | 录入检验结果 | 某个结果记录事务是否仅查看、特定用户是否获授权 |
| `Q_QIRECPRC` | 编辑采购质量信息记录 | `QI03` 或 Fiori 应用的具体显示/编辑角色 |
| `Q_SMPLPROC` | 编辑抽样程序 | `QDV3` 或 Fiori 应用的具体角色、显示权限 |

这些是文档中的授权对象操作描述，不是逐事务授权映射表。`Q_TCODE` 和新授权对象的说明也不足以重建某个客户的 PFCG 角色。若需确认具体权限，应由授权管理员依据目标系统角色和授权值核实；本文未连接系统，未检查 SU24、PFCG 或用户主数据。

## 适合阅读学习的使用方式

1. 先按对象和动词找目标，例如“显示样品”或“记录结果”；不要只记住事务码。
2. 对照版本化来源确认入口关系。遇到只有更高版本来源的事务，不把它补进 2021 索引。
3. 将入口存在性、Launchpad 显示、用户授权、操作是否修改数据分别记录。一个证据不能代替另三个。
4. 无写权限或没有明确授权时，通过文章、官方截图或获准的培训环境学习；不在生产系统试开、保存、录入或过账。

## 尚未覆盖

- 这不是全部常用 QM 事务码清单；来源未逐项覆盖检验批显示/修改、结果查看、使用决策、检验计划、特性主数据和质量通知等入口。
- 现有证据未逐事务说明输入、输出、筛选条件、显示/修改模式和所需权限对象。
- 文档跨 Initial Shipment、FPS01、FPS02，不能说明具体工厂当前安装的 FPS 或客户系统启用情况。
- 新旧授权对象的操作语义不能替代每个事务码的角色映射；未核实任何用户的实际权限。

上述缺口涉及本篇核心目标，故状态保持 `drafting`。不由业务功能名称推定事务码，也不把没有出现在该清单中的事务解读为不存在。

## 可选练习（无需系统操作）

将下面三类说法分别标成“来源支持的入口变化”“来源支持的操作标签”“尚未验证的授权结论”：

1. `QE51` 在该版本来源中不再提供，并列出 `QE51N` 替代。
2. `QS34` 的功能标签是检验方法版本显示。
3. 某位检验员一定能通过 `QS34` 查看全部工厂的检验方法。

参考：前两项是来源支持的变化/标签；第三项涉及实际用户、组织范围和系统权限，不能由这份产品来源推出。
