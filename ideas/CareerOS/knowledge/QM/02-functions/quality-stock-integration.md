# QM-05｜质量库存与采购生产集成

- 文章 ID：QM-05
- 状态：drafting（M3 标记“暂缓核心”；本次复核未取得足以支撑一般 IM 质量库存、库存转移及财务影响的可复现目标版证据）
- 目标版本：SAP S/4HANA 2021 On-Premise；ECC 仅作必要差异对比
- 本文用途：记录已发现的来源、历史主张、当前证据缺口和下一步核验要求；暂不作为通用业务规则或 SAP 操作指南。
- 系统验证：未连接 SAP；没有查看客户库存、检验批、生产订单、权限、物料凭证或财务凭证，未做实机测试。

## 1. 当前结论

M3 将 QM-05 标为“暂缓核心”，要求补查一般 IM 质量库存与财务影响；逐篇计划还要求在同一案例中核对收货、检验、库存转移涉及的单据、数量和价值条件。M3 证据台账为 QM-05 登记的直接内容仅是动态 SAP S/4HANA 2021 SPS10 Feature Scope Description 的 EWM 仓储质量管理片段；该片段不能代替普通 IM 证据，也不能支持通用估价或 FI/CO 结论。

旧正文和同上下文 Work 审查记录引用了三个带 `version=2021.000` 的 SAP Help 页面，并记录了一些收货、库存相关性和库存过账主张。本次复核重新尝试直开这些固定版页面，三者均返回不可访问。旧记录没有保留可逐句复核的固定版原文摘录；当前未锁版本的同名搜索材料不能证明其内容适用于 2021.000。因此，下文把这些内容作为**待验证主张**登记，不把它们当作本次已确认的 SAP 规则。

## 3. 已知范围边界与待补核心

- **采购收货与生产收货**：既有记录曾将生产完成后的收货作为一个收货来源，但该来源记录不能推出生产订单释放触发、生产中检验、生产确认与收货的自动联动，或采购/生产/检验批/会计凭证的对象关系。
- **一般 IM 与 EWM**：M3 台账中的动态 FSD 11.0/SPS10 §2.8.5.2 仓储质量管理材料属于 EWM 专属范围；它不能支撑一般 IM 检验库存规则。本篇不引用 EWM origin 17、部分使用决策或仓库任务作为一般 IM 证据。
- **使用决策与库存转移**：QM-04 目前仍为 Draft，且其固定版结果/使用决策和库存过账页面本轮未能复读。它不能作为已验证的过账前提、时点、目标类别或自动化规则来源。
- **数量、价值和财务**：当前没有足够固定版直接证据支持逐移动类型数量变化、库存估价、价值变化条件、会计科目或 FI/CO 凭证。不得把物料凭证等同于财务凭证，也不得据库存状态推算借贷分录。
- **冲销与退货**：通用冲销对象、部分数量、退货限制和估价后果仍未由本篇的可复现目标版证据证明。
- **配置与权限**：没有证据支持客户的检验类型/业务配置、角色映射、授权对象、只读入口或当前系统行为；不提供这些方面的操作步骤。

因此本文不呈现确定的放行、报废、退货、自动过账或财务流程，也不将待核主张画成 SAP 事件顺序。

以下是后续核对资料时的问题，不是系统操作步骤或已验证流程：

4. 它是否明确描述使用决策、可过账数量、库存目标类别、部分量和撤销条件？
5. 价值与 FI/CO 影响是否由独立的固定版来源支持？若没有，保持未知。
6. 页面是否证明客户配置或用户权限？如未证明，不推断客户实际行为或只读能力。
7. 若引用物料凭证、检验批或生产对象，是否有独立证据支持对象链接、字段、键和基数？
