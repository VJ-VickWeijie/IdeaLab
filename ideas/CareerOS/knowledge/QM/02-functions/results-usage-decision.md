## 1. 当前可以确认的事实

SAP 官方检索结果中，固定版 version=2021.000 的 [Manage Inspection Lots](https://help.sap.com/docs/SAP_S4HANA_ON-PREMISE/e296651f454c4284ade361292c633d69/eec27eaaa6b6499687148df6e52c34ad.html?version=2021.000) 条目报告：该应用工作清单可记录检验结果，也可作使用决策（usage decision，UD）。检索结果将其置于 SAP S/4HANA 2021 文档范围内。

本轮直接打开该版本链接后，SAP Help 返回 0 行可读正文。因此，这里只确认“官方索引在该固定版本条目下显示了这些工作清单动作”，不声称本轮读过页面正文；也不推断两项动作的先后顺序、状态机、字段、权限或自动化条件。

## 2. 当前不作为 2021 固定版规则的旧稿内容

此前草稿还写了 UD 的完整前提清单、手工/多批/周期作业处理方式、库存过账时点和目标、物料凭证、目录类型 3 的自动过账条件等细节。尽管这些说法出现在 SAP Help 的一般检索内容中，本轮目标版核验没有获得可读的固定 2021 正文：

- 固定 2021.000 的 [Usage Decision for Inspection Lot](https://help.sap.com/docs/SAP_S4HANA_ON-PREMISE/2bc3ee8d1c83404e8cf62418640004f2/3a7fb6535fe6b74ce10000000a174cb4.html?version=2021.000) 本轮打开不可访问。可见的未锁版本检索内容没有可核验的 2021 版本标签，因此不用于目标版结论。
- 固定 2021.000 的 [Stock Postings](https://help.sap.com/docs/SAP_S4HANA_ON-PREMISE/2bc3ee8d1c83404e8cf62418640004f2/06edba53422bb54ce10000000a174cb4.html?version=2021.000) 本轮打开不可访问。当前 SAP Help 检索结果明确标为 2025 FPS01（Feb 2026），已排除。
- 既有 M3 来源记录留有先前版本选择与局部复读说明，但没有为 QM-04 保存可在本轮重读的目标版正文摘录。该历史记录仅用于交代取证沿革，不能替代本次缺失的可复核证据。
- SAP S/4HANA 2021 FSD latest 早前直读为 11.0 / 2026-07-22 / SPS10；它不是固定的 2021.000 版本。本篇不以该动态快照补充固定版 UD 或库存规则。

这并不表示上述产品规则必然不存在；只表示目前没有足够、可复核的目标版材料来把它们写成 S/4HANA 2021 通用事实。

## 4. 离线学习练习：把事实和待查项分开

假设采购收货后存在一个质量检验批。现在只根据本文可引用的 2021.000 官方索引，练习给下列陈述贴标签：

| 陈述 | 当前可否当作已证实的固定版规则？ |
| --- | --- |
| Manage Inspection Lots 工作清单包含“记录检验结果”和“作使用决策”两项能力。 | 仅可按官方 2021.000 检索结果引用；页面正文本轮不可读。 |
| 结果录入已完成，因此 UD 一定可以执行。 | 不能。UD 的目标版前提尚未取得。 |
| 作了 UD，因此库存已转到某一库存类别。 | 不能。过账关系、时点和目标未由可复核的固定版材料证实。 |
| 系统可以定期自动作 UD，或类型 3 代码会自动过账。 | 不能。当前来源不足以确认这些规则适用于目标版。 |
| 即使某次库存过账生成物料凭证，也能据此推断一定产生 FI 凭证或金额变化吗？ | 不能。目标版会计影响尚未核实。 |

这是证据分辨练习，不是客户系统操作步骤或实机验证。
