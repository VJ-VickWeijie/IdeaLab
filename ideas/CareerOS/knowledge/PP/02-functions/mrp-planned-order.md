## MRP 先解决什么问题

物料需求计划（Material Requirements Planning，MRP）要协助计划人员查看某种材料的需求与供应是否需要进一步处理。按 SAP 的 SAP S/4HANA 2021 Feature Scope Description（FSD）当前文件版本，MRP 的高层目标是检查材料可用情况；计划运行发现短缺时，可以产生采购申请（purchase requisition）或计划订单（planned order）等补货提议。需求示例包括销售、库存调拨和生产需求；FSD 也描述了供需监控工具和库存/需求清单。该 FSD 还把 MRP 说明为覆盖需求与供应要素，但不考虑现有产能；产能计划用于在满足需求时间/数量的同时考虑能力约束。此区分只按动态 FSD 的 2021 SPS10 快照表述，不是固定 2021.000 的证据。

这里的证据有一个重要限制：SAP FSD 的文件 URL 是动态的。Work 直接打开该 PDF 时，文件历史表列出文档版本 11.0、日期 2026-07-22、对应 SAP S/4HANA 2021 SPS10；同一 URL 的搜索索引快照仍显示旧版本 9.0、日期 2025-07-23、对应 SPS08。搜索索引与直接读取结果不一致，且未归档本地 PDF 哈希。以下有关计划流程的句子只对应直接读取并记录的 SPS10 文档快照；不把它说成 2021 初始版静态页面，不宣称动态 URL 可锁定版本，也不外推到其他 FPS/SPS 或客户设置。

## 计划订单是什么

在上述 2021 SPS10 FSD 的范围描述中，计划订单是内部计划要素，用于计划，并不等同于采购订单或已下达的生产订单；一般情况下，它本身不会直接启动采购。资料单独说明，重复制造场景可能使用计划订单触发生产，因此不能把“一般不直接采购”改写成“计划订单在任何场景都不会触发后续动作”。

FSD 描述了几种可能的后续处理：自制材料的计划订单可转换为生产订单；流程制造场景可转换为流程订单；外购材料的计划订单可转换为采购申请。相应转换可以手动执行或由转换运行处理。重复制造是单独例外。本文只介绍这些有限的对象边界，不把转换资格、自动作业调度、订单状态或组件预留规则讲成所有客户共通流程；这些是 PP-05 及相应配置资料需要另行核实的内容。

FSD 将 MRP 的需求/供应覆盖与产能计划分开：计划提议及其日期不等于产能已核实、工序已排定或生产已获准执行。这里仅按 SPS10 FSD 的范围描述作概念区分，不能由此判断客户系统中的日期算法或产能校验结果。

因此，读 MRP 结果时先区分：

| 对象/信息 | 入门理解 | 本文可以确认的边界 |
| --- | --- | --- |
| 需求（requirement） | 需要某种材料的数量和时间信息 | FSD 高层说明列举了销售、库存调拨和生产等需求背景；完整纳入规则未闭合 |
| 现有库存及预期供应 | 判断计划时可看到的供需要素 | 不能据此断言具体库存类型、预留、在途量、日期或库存段一定如何计入 |
| 计划订单 | 面向内部计划的补货提议之一 | 2021 SPS10 FSD 将其描述为内部计划要素；具体数量和转换条件受未核实规则影响 |
| 采购申请 | 外购补货路线的提议/单据 | FSD 说明 MRP 可以产生采购申请；不能由此推断供应商、采购订单或付款已确定 |

## 需求短缺不等于固定的计划订单数量

SAP 2021 SPS10 的 FSD 说，计划运行检查材料可用性，并在发现短缺时产生采购申请或计划订单。它没有在该段落给出一条可覆盖所有系统的净需求公式，也没有逐项定义哪些库存、预留、已计划收货、计划参数或分段要素必须计入。因此，本文不把简单的“需求减库存”算式写成产品算法。

下面只是纸面算术练习，不是 SAP 算法、MRP 运行或预期系统结果：

- 虚构材料：FG-100；统一教学单位：件。
- 教学假设：题目给定期初余额 25（不是 SAP 算出的可用库存），预计供应 15 且仅按本题假设在需求日及时到达，某一日期的需求 50。
- 只做本题定义的余额差：50 − 25 − 15 = 10 件。
- 另设教学假设：本题暂按缺口 1:1 补足，不考虑最低/最高批量、舍入值、损耗、安全库存、预留、不同日期、分段、BOM 展开、采购提前期或工厂/计划范围。
- 这个 10 件只回答题目人为定义的算术余额；不能写成 SAP 会创建 10 件计划订单的结论。实际 MRP 结果及提议类型必须按目标系统的物料、组织和计划设置验证。

这样练习的目的，是让读者先标出“需求、库存、预计供应、日期与单位”这些需要澄清的数据，而不是背一条未经证明的 SAP 公式。

## 2021 版可直接确认的有限入口

1. **MRP 结果监控**：固定版 SAP Help 官方检索索引的“Monitor Material Coverage”条目标注 SAP S/4HANA 2021（Oct 2021，version 2021.000）及 Scope Item J44，并摘录该应用两个新增能力：intraday supply，以及参照 safety time 的 shortage 显示。规范 HTML 直开为 0 行可读正文，因此本文只按官方索引摘要支持这两个有限应用能力；它不是净需求或批量算法手册。
2. **计划订单 API**：固定版 SAP Help 官方检索索引中的 2021 What's New 条目记录 Planned Order OData API（API_PLANNED_ORDERS），可读取、创建、更改和删除计划订单，并列出 BJ5、J44 范围；索引还建议使用 Planned Order OData V4 服务管理计划订单。规范 HTML 直开为 0 行可读正文，故本文只按索引摘要支持该 API 的有限版本/场景范围，不证明客户系统已启用、调用者已获授权，也不提供完整数据字段契约。
3. **MRP 运行准备事项**：SAP《Operations Guide for SAP S/4HANA 2021》所读文件版本 11.0（2026-07-22，SPS10）在 MRP 运维章节说明了 MRP 记录、物料主数据 MRP 视图/MRP type 前提及 MRP Live 的总需求清理事项。这些是 SPS10 运维准备提示，不是完整的计划资格清单；不能取代计划算法说明，也不能证明某客户材料会参加某次运行、某客户系统满足前提或 MRP Live 与经典计划结果等价。
4. **高层范围提示**：同一 FSD 的第 2.8.3.1 节描述计划运行、短缺补货提议、供需监控和计划订单性质。因为这是动态 URL 上的 SPS10 文件快照，正文已披露其文件版本和日期；它不是 2021.000 初始版页面。
5. **迁移范围内的物料主数据变化**：SAP S/4HANA 2021 Simplification List §3.24（PDF pp.150–151）属于系统转换/升级说明，提到 MRP 主数据字段变化，包括 MRP1 的 Unit of Measure Group，以及系统转换后配额安排的处理变化。它不能代替日常 MRP 的净需求或批量计算说明；本文不从这项迁移说明推导计划结果。

## 还需要补证的核心规则

以下项目是 PP-04 的核心学习目标；在找到与声明相匹配的 SAP S/4HANA 2021 On-Premise 直接来源前，保持待核：

- 净需求计算中各类库存、预留、收货要素、需求日期与分段如何纳入；是否存在不同 MRP 类型或场景分支。
- lot-sizing 程序以及最低/最高数量、舍入、损耗、安全库存对计划提议数量的影响和计算顺序。
- 采购/自制类型、特殊采购、生产版本/BOM 展开、交期排程如何共同决定采购申请、计划订单或其他提议。
- MRP 运行模式、计划范围、需求日/收货日处理、计划时界与 firming、变更计划/再生计划、MRP Live 与经典计划的适用差异及客户系统行为；不能假定提议日期代表产能可行或两种运行模式结果等价。
- 计划订单字段、数据库数据模型、API 完整契约、状态、授权与当前客户系统是否启用。
- 对计划建议的确认、冻结、转换或重排何时改变业务责任、库存或成本；金额和 FI/CO 影响不在本稿中推断。
