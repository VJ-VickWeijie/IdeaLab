# PP-05｜生产订单与确认

- 状态：drafting（证据受限草稿；同一上下文角色视角模拟不等于独立 review）
- 目标版本：SAP S/4HANA 2021 On-Premise
- 本稿范围：说明生产订单与计划订单的对象边界，并介绍 2021 资料直接列出的生产准备、发料、确认、收货和状态监控范围。

## 生产订单与计划订单不是一回事

计划订单是供计划使用的提议；动态 SAP S/4HANA 2021 Feature Scope Description（FSD）版本 11.0/SPS10 在 §2.8.3.1 的离散制造段落说明，可把厂内生产物料的计划订单转为生产订单，手动或通过转换作业执行。这里仅指该 SPS10 文档明示的离散制造厂内生产场景，不据此补出适用资格、前提或客户配置规则。§2.8.4.2 另概述备料、领料、工时票/确认、完工收货等生产执行事项。

本文引用的 FSD 链接是动态 URL。实际读取到的文件标为 SAP S/4HANA 2021 Feature Scope Description 文档版本 11.0，日期 2026-07-22，对应 2021 SPS10。本文只把它作为明确标注的 SPS10 快照参考，不称为固定版 2021.000 初始页面，不外推到其他版本或客户设置。

## 生产订单执行中有哪些不同记录

| 记录/动作 | 学习时要分清的事 | 本文可支持的范围 |
| --- | --- | --- |
| 生产订单 | 表示一项计划生产任务进入生产执行对象范围 | 动态 FSD §2.8.3.1（2021 SPS10）说明离散制造中的厂内生产物料计划订单可转为生产订单；该项不代表其他制造方式，也不提供通用资格条件 |
| 释放（release） | 一个需单独核对前提和权限的订单处理动作 | 固定版 2021 SAP Help 官方检索索引摘要列出生产订单释放中的文档授权检查；它不提供通用释放状态表或全部前提 |
| 生产确认（production confirmation） | 记录生产进度的操作类别 | 动态 FSD §2.8.4.2（2021 SPS10）称确认记录订单处理状态，并可触发订单数据更新、组件反冲、收货过账、成本更新等示例；也说明可以取消或部分取消确认。它没有给出各动作的完整触发条件或撤销后果。固定版 2021 API 索引摘要只列创建前的提议数据类别，不是已保存确认、已过账物料凭证或完整请求载荷 |
| 货物移动 | 物料领用或完工收货等库存事件 | SPS10 FSD 将发料/收货列作生产执行事项，并列出确认可能触发的示例；不表示每次确认都会发生每一种移动，也不说明客户设置、失败处理或凭证顺序 |
| 技术完成（technical completion） | 从物流视角标记生产订单完成的一项状态处理 | 动态 FSD §2.8.4.1（2021 SPS10）称该状态下订单不再与 MRP 相关、预留和产能需求会被删除；订单不可再更改，但仍可发生如物料领用或确认的过账。关闭（close）后才不再允许后续更新。该快照不提供全状态迁移表 |
| 结算（settlement） | 将订单实际成本分配到一个或多个接收成本对象的后续处理 | 同一 SPS10 FSD 概述接收方示例（如产出物料或销售订单）；它没有说明 TECO 会自动触发结算，也不提供完整结算规则、金额算法或 FI/CO 分录，须由 PP-06/CO-04 另按来源核对 |

SAP Help Portal 的 S/4HANA 2021 官方检索索引摘要还说明，可在 BJ5 范围的 Production Order Object Page 查看已记录的货物移动，并在用户具有相应角色时导航到相关应用。它只证明该固定版索引所列的应用能力，不保证客户启用该页面或用户具备相应授权。

## 不能把“报工”当成所有后续动作的通用开关

确认（confirmation）与货物移动（goods movement）可能有关联，但不能被当成同一记录或必然同步发生的动作。SPS10 FSD 明确列出确认会触发订单数据更新、组件反冲、收货过账和成本更新等示例；同一段另说明确认可取消或部分取消，并将货物移动重处理列为一项可用处理。它没有说明取消确认会自动触发重处理，也没有给出每项触发示例的具体配置/条件、取消后的物料凭证逆转关系或失败回退规则。固定版 2021 API 官方索引仅说明创建确认前可获取提议数据，对应的确认/移动请求字段、物料凭证关联键/基数和写入结果本轮不可读。故本文不能推断每次报工都自动扣料、自动入库或自动产生特定 FI 凭证，也不能从页面导航角色或文档授权检查推出确认 API 的写入授权。

同样，本文不把“生产订单已创建”与“生产已获准执行”混为一谈。S/4HANA 2021 BJ5 的官方检索索引摘要显示，释放时自动附加文档会按文档对象、类型和状态执行特定授权检查，缺少授权时可拒绝释放；这不是完整释放规则或通用权限矩阵，也没有给出全部订单状态迁移。

## 离线学习练习：把事件分类并标记待核顺序

无需登录 SAP，为一个虚构生产任务制作事件分类表或事件图。以下是完成练习的步骤，不代表业务事件顺序；练习不设普遍事件先后关系，凡尚无目标版直接证据的顺序均标成“待核”：

1. 先标注一条计划订单，写下“这是计划提议”。
2. 再画出“转成生产订单”这一候选步骤，并在旁注明：本例只用于学习离散制造范围，转换条件未在本篇核实。
3. 将“订单释放”“记录确认”“组件领用”“完工收货”“技术完成”“结算”“关闭”作为不同的候选事件分别列出；不要根据这个列举顺序连成流程。
4. 对每个事件标出需要查的对象、责任角色、数量/时间、库存或成本影响、系统配置和权限。
5. 暂不假设任何事件一定发生，也不写自动扣料、自动收货、撤销方法或 FI 分录。

练习用于训练单据边界和证据意识，不是 SAP 操作指导，不代表一条已验证的标准配置流程。

## 待补的核心规则

- 生产订单从创建、计划订单转换、释放、技术完成到关闭的固定版状态全集和允许的转换条件；目前 SPS10 FSD 只有限描述 TECO 与关闭，不是完整状态机。
- 订单类型、工厂、计划参数、主数据或订单控制对转换/释放条件的具体影响。
- 部分/最终/工序确认、确认数量差异及取消确认的固定版规则。SPS10 FSD 仅说明可以取消或部分取消，不给条件、后续状态及关联单据逆转结果。
- 发料、反冲、报废、完工入库与确认之间的详细触发前提、失败/回退和凭证顺序。SPS10 FSD 列出可能触发的示例，不构成固定版通用条件或客户设置证明。
- 生产订单/确认的数据模型、字段键、复合键、关联基数、released API 的完整合同及授权。
- 订单实际成本、差异、结算与 FI/CO 影响；这些需由 PP-06、CO-04 及相关固定版账务证据分别支持。

上面列的是本文未闭合的学习目标，不代表 SAP 不支持这些功能；在目标版直接证据补齐前，不将它们写成肯定的系统规则。
