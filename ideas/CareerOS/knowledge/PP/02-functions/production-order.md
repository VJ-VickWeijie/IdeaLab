- 目标版本：SAP S/4HANA 2021 On-Premise
- 本稿范围：说明生产订单与计划订单的对象边界，并介绍 2021 资料直接列出的生产准备、发料、确认、收货和状态监控范围。

## 生产订单与计划订单不是一回事

计划订单是供计划使用的提议；在 SAP S/4HANA 2021 SPS10 Feature Scope Description（FSD）的有限描述中，离散制造的自制计划订单可转换为生产订单。生产订单由此进入更接近生产执行的对象范围。FSD 还分别列出备料、记录领料、处理工时确认、录入完工收货信息和记录生产活动等执行事项。

本文引用的 FSD 链接是动态 URL。实际读取到的文件标为 SAP S/4HANA 2021 Feature Scope Description 文档版本 11.0，日期 2026-07-22，对应 2021 SPS10。本文只把它作为明确标注的 SPS10 快照参考，不称为固定版 2021.000 初始页面，不外推到其他版本或客户设置。

## 生产订单执行中有哪些不同记录

| 记录/动作 | 学习时要分清的事 | 本文可支持的范围 |
| --- | --- | --- |
| 生产订单 | 表示一项计划生产任务进入生产执行对象范围 | 动态 FSD 的 2021 SPS10 高层描述支持“自制计划订单可转换为生产订单”的离散制造示例；不代表所有订单类型或制造方式 |
| 释放（release） | 一个需单独核对前提和权限的订单处理动作 | 固定版 SAP Help 2021.000 对生产订单释放中的文档授权检查有特定说明；它不提供通用释放状态表或全部前提 |
| 生产确认（production confirmation） | 记录订单执行中的数量、活动或时间等信息的操作类别 | 固定版 2021 API 页面说明：在写入生产订单确认前可请求数量、工作活动、日期/时间、人员和货物移动等提议数据；这不等于本文确认了所有字段或过账联动 |
| 货物移动 | 物料领用或完工收货等库存事件 | FSD 把领料和完工收货作为生产执行事项列出；不能据此断言每次确认都会自动过账某个移动 |
| 技术完成/结算 | 生产订单生命周期中的后续管理事项 | FSD 快照提到技术完成及结算，但本篇不解释完整状态转换、结算接收方或金额计算；财务与成本依赖留给 PP-06/CO-04 按来源核对 |

SAP S/4HANA 2021 固定版 Help 的 Production Order Object Page 页面还说明，可在该对象页查看已记录的货物移动，并在用户具有相应角色时导航到相关应用。它只证明该页面在对应范围提供这类信息，不保证客户启用该页面或用户具备相应授权。

## 不能把“报工”当成所有后续动作的通用开关

确认（confirmation）与货物移动（goods movement）需要分别核对。2021 固定版 API 条目把确认数据提议与货物移动提议列为在创建确认前可读取的不同内容；生产订单对象页也把已记录的货物移动作为单独信息区域。以上资料不能支持“每次报工都自动扣料、自动入库、自动产生 FI 凭证”的说法。

同样，本文不把“生产订单已创建”与“生产已获准执行”混为一谈。固定版 2021 Help 确认 BJ5 范围存在生产订单释放相关处理，并对自动附加文档时的授权检查作出说明；它没有在本次读取范围内给出所有释放条件或完整的系统/用户状态迁移表。

## 离线学习练习：为事件标注证据

无需登录 SAP，给一个虚构生产任务画出时间线：

1. 先标注一条计划订单，写下“这是计划提议”。
2. 再画出“转成生产订单”这一候选步骤，并在旁注明：本例只用于学习离散制造范围，转换条件未在本篇核实。
3. 将“订单释放”“记录确认”“组件领用”“完工收货”“技术完成”作为不同的候选事件分别列出。
4. 对每个事件标出需要查的对象、责任角色、数量/时间、库存或成本影响、系统配置和权限。
5. 暂不假设任何事件一定发生，也不写自动扣料、自动收货、撤销方法或 FI 分录。

练习用于训练单据边界和证据意识，不是 SAP 操作指导，不代表一条已验证的标准配置流程。

## 待补的核心规则

- 生产订单从创建、计划订单转换、释放到技术完成/关闭的目标版状态全集和允许的转换条件。
- 订单类型、工厂、计划参数、主数据或订单控制对转换/释放条件的具体影响。
- 部分确认、最终确认、里程碑/工序确认、确认数量差异、撤销确认的目标版行为。
- 发料、反冲、报废、完工入库与确认之间的触发关系、失败/回退和凭证顺序。
- 生产订单/确认的数据模型、字段键、复合键、关联基数、released API 的完整合同及授权。
- 订单实际成本、差异、结算与 FI/CO 影响；这些需由 PP-06、CO-04 及相关固定版账务证据分别支持。

上面列的是本文未闭合的学习目标，不代表 SAP 不支持这些功能；在目标版直接证据补齐前，不将它们写成肯定的系统规则。
