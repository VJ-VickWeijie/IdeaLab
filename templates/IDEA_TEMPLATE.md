# 项目名称

## 灵感卡

- **一句话想法**｜我想做什么？
- **灵感起点**｜遇到了什么、看到了什么，或者好奇什么？
- **最想保留的点**｜哪一部分最让我想继续做？
- **当前状态**｜灵感 / 调研 / 验证 / 开发 / 完成 / 搁置
- **下次打开时**｜写一个具体行动，或留一个想弄清的问题。
